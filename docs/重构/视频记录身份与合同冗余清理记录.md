# 视频记录身份与合同冗余清理记录

## 搜索覆盖范围

本专项从章节视频列表、播放、采用、编辑、删除、上传、裁剪、成片拼接、推送后处理和模型请求预览功能出发，按 BFS 追踪完整生产链路：

```text
VideoTab / VideoResultsPane / VideoAssemblyWorkspace / VideoPostProcessWorkspace
StudioCanvasNode / CanvasNodeContentPreviewDialog
→ frontend api/video/records、api/video/generation
→ apiInvoke
→ Web Bearer token / Tauri invoke_host_command.user_id
→ Server video 与 system/collaboration dispatch
→ video_records records / assembly / uploads / processing handlers
→ video_generation preview handlers
→ Runtime video_records / video_generation
→ Orchestrator video records / chapter generation / reference-media generation
→ project Viewer / Editor permission
→ DB generated_video / chapter_video_prompt / video timeline
→ media binding / canvas reference / generation target 清理
→ data、temp、assembly cache、FFmpeg、thumbnail、cleanup outbox、provider snapshot
```

隐式依赖覆盖 command manifest context/schema、Host TypeScript 生成器、Web 认证、Tauri 外层身份、runtime config snapshot、文件输入声明、视频 provider Host Port、删除生命周期 Host Port、后台清理 outbox、成片缓存清理和持久化引用清理。仓库中没有这些命令对应的 XML DI、反射、动态代理或 AOP；动态入口只有 Host 命令分派，已纳入闭包。

## 清理前分叉

```text
Web JWT / Tauri invoke_host_command.user_id
→ Server user_id
→ Runtime / Orchestrator 权限校验

frontend api/video/records
→ 18 个调用再次发送 userId
→ Server handler 从不读取该业务字段

update_video 请求
→ a4n-api-contract 严格 nullable patch
→ Orchestrator 另一套旧 DTO（clear_*、metadata、位置移动字段）
→ negative_prompt: null 无法表达“清空”

视频收藏
→ 通用 update_video
→ 遗留 toggle Runtime / Orchestrator / Context / DB 第二套完整实现

成片状态与后处理操作
→ 前端字符串联合类型
→ Orchestrator 自由字符串 DTO 与运行时兜底校验
```

36. `preview_video_provider_request_by_video_id` 只读取持久化 provider snapshot，删除无效的 runtime-config policy 与视频 provider capability 依赖。
37. Host TypeScript 生成器输出推送动作、后处理操作和状态更新唯一合同，前端直接复用。
38. 新增 manifest 身份/严格 schema/typed result 回归，并新增 nullable patch 与空 patch 回归。

## 清理后唯一事实标准

```text
用户身份
→ Web：Bearer token 认证出的 user_id
→ Tauri：invoke_host_command 外层 user_id

视频更新合同
→ a4n-api-contract::video::UpdateGeneratedVideoInput
→ prompt / negative_prompt / is_favorite

收藏更新
→ update_video 唯一写路径

推送动作与后处理操作
→ a4n-api-contract::video 枚举

响应合同
→ a4n-api-contract::video / request_preview
→ frontend generated/host.ts
```

未新增旧参数兼容、默认用户、身份覆盖、缺失 input 回退、DTO 别名或 transport 适配器。
