# 认证启动状态冗余清理记录

## 搜索覆盖范围

本专项从应用启动时的认证门禁出发，按 BFS 追踪完整生产链路：

```text
main / portable storage 初始化
→ AuthGate
→ Zustand auth.init
→ authStorage 中的 user/session/access/refresh 凭据
→ apiInvoke
→ Web access-token 自动刷新 / Tauri invoke_host_command
→ Server authenticated_user / Tauri user_id context
→ Runtime auth_records
→ Orchestrator auth port
→ DB current_user / active_user
```

横向覆盖登录、注册、OAuth、登出、401 失效、主题启动、账户设置和 E2E 注入路径。隐式依赖覆盖 React StrictMode 下的并发 `init`、`AUTH_UNAUTHORIZED_EVENT`、浏览器与 Tauri portable storage、Web refresh-token 轮换、command manifest 以及 disabled user 校验。仓库中没有认证相关 XML DI、反射、动态代理或 AOP。

## 清理前分叉

```text
服务端会话事实
→ access token / refresh token / session
→ get_current_user
→ DB active_user

前端第二事实源
→ a4n:auth:bootstrap:v3
→ 缓存完整 UserSummary 10 分钟
→ 服务端校验完成前设置 initialized=true 和 user
```

缓存用户可能已被禁用、删除或退出，但 AuthGate 会先按旧快照放行；随后由任意业务请求触发 401/403 才纠正。缓存还独占一套 debounce、idle callback、写入去重和待提交状态。

## 优化记录

1. 认证启动只以 `get_current_user` 返回的 active user 为登录事实。
2. 删除启动时读取 `a4n:auth:bootstrap:v3` 用户快照的路径。
3. 删除缓存命中后提前设置 `initialized=true` 的伪成功路径。
4. 删除认证初始化成功后的用户快照写入。
5. 删除登录成功后的重复用户快照写入。
6. 删除 OAuth 登录成功后的重复用户快照写入。
7. 删除注册成功后的重复用户快照写入。
8. 删除登出后的空用户快照写入。
9. 删除 401 处理后的空用户快照写入。
10. 删除 `AuthBootstrapSnapshot`、缓存 key、TTL 和 `saveAuthSnapshot`。
11. 删除只服务于缓存的 `bootstrapCache` 模块及其 pending write、序列化去重和延迟提交逻辑。
12. 删除零剩余消费者的 `scheduleIdleTask` 模块。
13. 删除 AuthStore 无 UI 或业务消费者的 `loading` 第二忙碌状态。
14. 删除零调用的 `reloadStatus` 动作。
15. 删除零调用的 `refreshMe` 动作。
16. 删除只为上述分叉服务的 `clearInvalidAuthSession` helper 和 Zustand `get` 依赖。
17. 删除登录、OAuth、注册和登出中的无效 `initialized=true` 重复赋值；这些动作只在 AuthGate 初始化完成后可达。
18. 删除 `onUnauthorized` 未使用的 message 参数和未消费的 CustomEvent detail。
19. 新增最小回归，验证启动期间不会提前恢复用户，且未授权会清空本地会话。

## 清理后唯一事实标准

```text
本地存储
→ 只保存 Host 调用必需的 user_id / session / tokens

登录用户对象
→ 只来自登录、注册、OAuth 的 AuthResult
→ 或启动时服务端 get_current_user 的 active-user 校验结果

AuthGate
→ 校验完成前保持未初始化
→ 校验成功后才进入业务界面
```

未新增缓存兼容、旧 key 清理器、离线用户回退、默认用户或认证失败占位逻辑。
