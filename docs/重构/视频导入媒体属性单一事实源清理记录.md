# 视频导入媒体属性单一事实源清理记录

日期：2026-08-16

## BFS 搜索覆盖范围

本批从视频导入功能出发，覆盖章节视频导入、参考媒体视频导入、成片衔接片段导入和 Canvas 视频导入四条入口：

```text
前端上传/API 与 Canvas file_path/data_base64 输入
→ command manifest / Server dispatch / Canvas Host Port
→ Runtime uploaded_video_source 或本地文件 source
→ FFprobe 属性读取与错误映射
→ Orchestrator 各类 imported video record validator
→ Runtime 文件复制、缩略图、尾帧、完成状态与失败清理
→ DB generated_video / timeline / media asset / checkpoint
```

横向对比确认四条路径的业务差异只在权限、规划合同、workflow、输出目录、缩略图和章节尾帧；“FFprobe 结果转换为 `ImportedVideoProperties`”没有差异，收敛为 source/probe 模块唯一 owner。未运行测试或任何构建验证。
