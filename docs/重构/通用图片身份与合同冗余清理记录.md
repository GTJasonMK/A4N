# 通用图片身份与合同冗余清理记录

## 搜索覆盖范围

本专项从图片图库、章节图片、视频参考图、手工上传、记录更新与删除、场景图/漫画页/批量图片预览和正式生成出发，按 BFS 追踪完整生产链路：

```text
ImagesTab / ImageGalleryPanel / ImageActionDialog
VideoTab / VideoMaterialWorkspace / VideoGenerationWorkspace
MangaTab / MangaChapterDetailPanel / SinglePortraitDialog
ObjectProfiles / SceneProfiles / Canvas / Galgame 资产生成
→ frontend api/image/{queries,records,generation}
→ objectProfiles / sceneProfiles / generationClient / apiInvoke
→ generated Host contracts / generation contracts
→ Web Bearer token / Tauri invoke_host_command.user_id / CLI command catalog
→ Server assets_and_media / video dispatch / generation route
→ image records / image preview handlers / command manifest
→ Runtime image_records / image_generation / runtime config request scope
→ Orchestrator image_record_lifecycle / image_generation / batch application
→ ImageGenerationHostPort / workflow / checkpoint / cleanup outbox
→ DB generated_image 创建、更新、查询、删除与引用清理
→ data/projects/*/images 与 chapters/*/images 文件持久化
→ 漫画页绑定、视频帧与参考图库、档案主素材、画布媒体资产
→ 依赖图、资产血缘、项目复制/导入导出和媒体路径下游
```

横向覆盖 13 条公开 Host 命令：

1. `list_images_by_project`
2. `list_images_by_chapter`
3. `list_video_reference_images`
4. `update_image`
5. `upload_image`
6. `delete_image`
7. `preview_scene_image_request`
8. `preview_page_image_request`
9. `preview_batch_images_request`
10. `start_image_generation`
11. `generate_object_profile_image_prompt`
12. `generate_scene_profile_image_prompt`
13. `preview_object_profile_image_request`

同时覆盖内部活跃入口：Canvas 图片导入与生成、Galgame 视觉图生成、视频提示词下游图片删除、依赖冲突清理、后台 generation worker，以及 `ImageGenerationHostPort` 的 provider、文件和血缘回调。

隐式依赖覆盖 command manifest schema/context/capability、Host TypeScript 生成器、generation schema、Web/Tauri/CLI 分发、runtime config snapshot、workflow business key、checkpoint fingerprint、cleanup outbox、项目权限和章节归属校验。仓库中不存在图片相关 XML DI、反射、动态代理或 AOP 旁路；动态入口只有 Host 命令分派、generation route、后台 generation worker 和 `ImageGenerationHostPort`，均已纳入闭包。

## 清理前分叉

```text
用户身份
→ Web JWT / Tauri 外层 user_id
→ 图片前端再次发送 userId
→ manifest context 再向 CLI 注入 userId/projectId/chapterId

图片记录合同
→ 顶层 projectId/imageId
→ 内层 input
→ Server 手工字段解析
→ Runtime 再拆成位置参数

图片预览合同
→ 三条 opaque manifest
→ 前端 camelCase 参数
→ Server 手工逐字段读取
→ Orchestrator 私有 Scene/Page/Batch DTO

批量请求
→ API Vec<Value>
→ Orchestrator Value
→ 三处 as_array() 重复格式校验

上传合同
→ API UploadImageInput
→ Orchestrator ImportedImageUploadInput
→ 非对象 metadata 再包装的不可达兼容分支

收藏与评分
→ 正式 update_image
→ 无 Host 调用者的 toggle/score 旧链
```

## 优化记录

1. `list_images_by_project` 改为严格 `{ input }`，项目 ID 只存在于 `ListImagesByProjectInput`。
2. `list_images_by_chapter` 改为严格 `{ input }`，删除重复顶层章节 context。
3. `list_video_reference_images` 改为严格 `{ input }`，删除重复顶层项目/章节 context。
4. `update_image` 将 `image_id` 收入 `UpdateGeneratedImageInput`，删除顶层 `imageId`。
5. `upload_image` 将 `project_id` 收入 `UploadImageInput`，删除顶层 `projectId`。
6. `delete_image` 新增唯一 `DeleteImageInput`，删除手写宽松 schema。
7. `preview_scene_image_request` 新增 `GenerateSceneImageInput`，删除手工 camelCase 参数解析。
8. `preview_page_image_request` 新增 `GeneratePageImageInput`，删除手工整数参数解析。
9. `preview_batch_images_request` 新增 `GenerateBatchImagesInput`，删除 `requestsJson` 动态参数。
10. 三条图片预览 manifest 从 opaque args/result 改为严格 typed args 和 `ModelRequestPreview` typed result。
11. `start_image_generation` manifest 改为严格 runtime input，退役额外身份参数。
12. 上述 10 条通用图片命令全部移除业务身份 context，认证身份只来自 Host。
13. `generate_object_profile_image_prompt` 移除重复用户 context。
14. `generate_scene_profile_image_prompt` 移除重复用户 context。
15. `preview_object_profile_image_request` 移除重复用户 context。
16. 前端图片 API 删除所有重复 `userId`，Web 和 Tauri 统一使用认证身份。
17. Server 图片记录入口统一使用 `strict_command_input`，删除 `i64_arg` 与宽松 `command_input` 分叉。
18. Server 三条图片预览统一使用 `strict_runtime_command_input`。
19. Runtime 查询、更新、上传和删除直接接收正式 DTO，删除位置参数身份拆分。
20. Orchestrator 删除 `SceneImageGenerationInput`、`PageImageGenerationInput`、`BatchImageGenerationInput` 三套私有镜像 DTO。
21. 批量请求从动态 `Value` 收敛为 `Vec<Value>`，删除三处 `as_array()` 与数组转换。
22. 批量 workflow business key、fingerprint 和 run input 直接消费切片，删除 JSON 容器分叉。
23. `image_project_ids` 改为必填且非空，删除缺失字段默认空数组。
24. `resolve_video_reference_image_project_ids` 删除“空数组自动扩展为全部允许项目”的隐式回退。
25. Orchestrator 直接复用 API `UploadImageInput`，删除 `ImportedImageUploadInput`。
26. 上传 metadata 在 API 边界限定为对象，删除内部“非对象再包装为 metadata 字段”的不可达兼容逻辑。
27. 删除 Runtime `toggle_image_favorite`；收藏状态唯一通过 `update_image` 更新。
28. 删除 Runtime `score_image`；评分唯一通过 `update_image` 更新。
29. 删除 Orchestrator 两层 toggle favorite 转发。
30. 删除 DB `toggle_generated_image_favorite_record` 旧实现。
31. 删除 Runtime `ImageGenerationProgress` 包装类型、默认静态实例和 `.inner()` 转发。
32. `generate_galgame_image` 删除永远传 `None` 的可选 progress 参数，直接使用 Orchestrator `ImageGenerationProgress::none()`。
33. 导入图片文件名改用 `timestamp_micros()`，删除纳秒不可表示时的第二套时间算法。
34. 生成图片文件名改用 `timestamp_micros()`，删除同类时间回退。
35. 批量取消和跳过项记录真实 `first_error`，不再依赖结果层补默认文案。
36. 批量中断或全失败却缺失错误时显式返回状态不变量错误，删除两条默认失败字符串。
37. 图片更新拒绝只有 `image_id` 的空补丁，删除无业务效果的更新路径。
38. 物体素材预览删除默认标题“物体”，缺失名称时显式报告状态错误。
39. 删除上传 `Option` 字段上无效的 `serde(default)` 注解。
40. Host TypeScript 生成器输出全部图片 DTO，前端不再维护镜像参数接口。
41. 生成器将 Rust `GeneratedImageSummary` 引用直接映射到前端唯一 `GeneratedImage`，删除临时类型别名。
42. 更新上传恢复集成测试为唯一 `{ input: { project_id, ... } }` 合同。
43. 新增 13 条图片命令身份、严格 schema 和 typed result 回归。
44. 新增批量取消真实错误回归，确保 provider 未调用且首错可审计。
45. 将取消测试从旧错误文案断言改为 `AppError::Cancelled` 语义断言，删除对展示字符串的耦合。

## 清理后唯一事实标准

```text
用户身份
→ Web：Bearer token 认证出的 user_id
→ Tauri：invoke_host_command 外层 user_id
→ CLI：认证会话；图片命令不再注入业务 userId/projectId/chapterId context

图片普通合同
→ Rust：a4n-api-contract::{image,image_generation}
→ TypeScript：frontend/src/api/generated/host.ts

图片正式生成合同
→ StartImageGenerationInput / ImageGenerationOperation
→ frontend/src/api/generated/generationContracts.ts

图片记录更新
→ update_image

图片上传
→ UploadImageInput

批量请求
→ Vec<Value> / unknown[]

生成进度
→ a4n_orchestrator::media::ImageGenerationProgress
```

未新增旧字段兼容、默认用户、身份覆盖、空项目范围扩展、metadata 包装回退、默认失败文案、默认物体名称、第二套时间算法、DTO 适配器或占位实现。
