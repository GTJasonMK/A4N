## 搜索起点与覆盖范围

以“用户创建、激活、导入、导出并应用主题”为功能起点，按广度优先顺序检查：

1. 前端入口：应用启动、状态栏亮暗切换、ThemeTab 列表/创建/重命名/删除/激活/导入/导出/CSS 查看、全量配置恢复后的主题重载。
2. Host 合同：`a4n-api-contract` command manifest、生成 Host 命令表、Tauri command registry/macro、Web Server dispatch、CLI capability 元数据。
3. Runtime：主题查询、变更、传输、CSS 输出、DB model 到 Host summary 投影及严格输入测试。
4. Orchestrator：同用户权限、全局主题可见性、owner 门禁、名称规范化、删除门禁、导入解析、配置 application/context facade。
5. DB：SeaORM `theme_config` entity、列表/创建/更新/删除/激活事务、管理员总览读取、全量配置导入导出写路径。
6. 隐式依赖：Serde/Schemars 生成类型、`ThemeMode` 领域枚举、PostgreSQL baseline/迁移注册/运行时 schema marker、前端便携状态 key、主题事件监听者。
7. 横向检查：全仓 Rust/TypeScript/CSS/测试引用，确认没有相关 XML、反射调用、动态代理、AOP 切面或额外路由表。

## 活跃调用拓扑

```text
application bootstrap / authenticated user change
  -> list_themes
  -> user active theme, otherwise global active theme
  -> apply css_variables to document root
  -> theme.mode is the only .dark authority
  -> theme-applied event refreshes non-React canvas consumers

ThemeTab list/create/update/delete/activate
  -> generated Host contract
  -> Tauri command or Web dispatch
  -> Runtime host whitelist
  -> Orchestrator permission and business rules
  -> typed ThemeMode + ThemeCssVariables
  -> a4n-db theme_config owner

export_theme
  -> authorized theme row
  -> strict persisted mode/css projection
  -> minimal CreateThemeInput JSON

import_theme
  -> frontend JSON parse
  -> strict CreateThemeInput Host deserialization
  -> the same create_theme business path

export/import all configs
  -> typed ThemeRow
  -> the same ThemeMode + ThemeCssVariables contract
  -> transactional settings import

admin overview
  -> active global theme
  -> strict ThemeMode projection
```

## 数据库迁移

新增不可逆迁移 `theme_config_integrity_contract`：

- 迁移前审计所有现有行；非法名称、mode、CSS 值、默认 scope 或重复身份会明确失败，不自动改写数据。
- `name` 必须非空且已 trim；`mode` 只能为 `light/dark`。
- `css_variables` 必须是 JSON object，所有 value 必须是 string。
- system default 只能属于全局 scope，且全表最多一个。
- 同一用户 scope（包括全局 NULL scope）内主题名称唯一。
- 每个用户 scope 最多一个 active，全局 scope 最多一个 active。

## 当前事实标准

主题只保留一套实现：Host 使用 strict typed 合同；Orchestrator 唯一拥有权限和业务规则；DB 接口与 PostgreSQL 约束共同保证持久化不变量；当前激活主题唯一决定 CSS 变量和亮暗模式；导出格式就是导入格式，不保留兼容包装或状态快照。
