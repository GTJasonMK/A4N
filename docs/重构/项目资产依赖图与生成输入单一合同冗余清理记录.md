# 项目资产依赖图与生成输入单一合同冗余清理记录

日期：2026-08-14

## 搜索起点与 BFS 覆盖范围

本专项从两个用户可见入口出发：

```text
App 全局“内容关联”入口
NovelDetail 项目内“内容关联”入口
```

按广度优先逐层追踪到以下完整生产闭包：

```text
AssetDependencyGraphDialog
→ frontend project API / generated Host TypeScript
→ Web apiInvoke 或 Tauri invoke_host_command
→ a4n-api-contract command manifest 与 typed schema
→ a4n-server 字符串 dispatch / project command macros
→ a4n-runtime project_records query adapter
→ a4n-orchestrator Viewer 权限校验
→ a4n-db project_dependency_graph
   ├─ 项目族 scope 与 graph records 批量读取
   ├─ GraphBuilder 节点、边、层级与下游计数
   ├─ node detail 各资产类型记录投影
   └─ generation_run_target → generation_run 输入快照补充
→ AssetDependencyGraph / AssetGraphNodeDetail Host 响应
→ graphCanvas 与详情/生成输入查看器
```

横向检查了 `generation_run` 七类真实 JSON 输入来源：

```text
rendered_messages_json
rendered_prompts_json
input_variables_json
source_refs_json
media_refs_json
request_json
response_summary_json
```

覆盖的活跃写入者包括蓝图、分部/章节大纲、章节正文、章节分析、人物与场景档案、图片、人物立绘、Manga、视频提示词和视频生成。所有写入者均通过 `serde_json::Value` 写入 PostgreSQL JSONB；依赖图只有 `details/generation_inputs/projection.rs` 一个响应构造器，不存在文本版或二次序列化版生产路径。

同时检查了以下隐式依赖：

- `generation_run_target` 的目标表/目标 ID 反向关联与项目族作用域。
- Domain → API contract → schemars → TypeScript 生成链。
- Web 字符串路由、Tauri 通用动态命令分发和认证用户身份注入。
- `AssetGraphNode.details` 到 generic node detail 的间接读取关系。
- `asset_lineage_sync`、项目包导入导出和 migration 中的 `legacy_table` / `legacy_id`。
- 图构建拓扑告警、缺失来源告警、生成输入状态和前端详情展示。

仓库不存在该功能对应的 XML DI、注解扫描、运行时反射注册、动态代理或 AOP 切面。动态入口只有 command manifest、Server 字符串 dispatch、Tauri 通用 dispatch 和 JSONB generation trace，均已纳入闭包。

## 清理后的唯一事实标准

- PostgreSQL `generation_run` 七个 JSONB 字段是模型生成输入的唯一持久化事实源。
- `generation_run_target` 是资产记录到 generation run 的唯一关联事实源。
- `generation_inputs_from_runs` 是依赖图生成输入响应的唯一投影实现。
- `GenerationInputSource` 只表达实际存在的 JSON：`group + kind + label + value`。
- 前端直接渲染 Host 返回的 JSON 值，不再猜测字符串是否是旧 JSON、重复 JSON 或转义文本。
- Workflow 详情自己的 `GenerationRunSummary` 仍负责展示运行元数据；项目依赖图不再复制一份无人消费的 run snapshot。

## 已完成优化

1. 删除 `AssetDependencyGraph.generated_at`；该请求时间戳无消费者且使相同图结果无意义地变化。
2. 删除 Host `AssetGraphNode.editable`；前端只使用已计算的 `mutable`、`downstream_count` 和 `mutation_policy`。
3. 删除依赖图专用 `GenerationRunSnapshot` 类型。
4. 删除 `AssetLineageRecord.generation_runs` 无人消费字段。
5. 删除 generation run 元数据到第二份 snapshot 的完整投影函数。
6. 删除所有资产 detail record 中重复的 `generation_runs: Vec::new()` 初始化。
7. 输入状态直接依据已加载的 `runs` 与真实输入判断，不再先构造无人使用的 snapshot 再反查。
8. 删除 `GenerationInputSource.id` 派生字段。
9. 删除 `GenerationInputSource.run_id` 无人消费字段。
10. 删除永远固定为 `json` 的 `GenerationInputSource.content_type`。
11. 删除永远为 `None` 的 `GenerationInputSource.text` 旧双通道。
12. 删除永远为 `None` 的 `GenerationInputSource.source_record_id`。
13. 将 `GenerationInputSource.value` 从可选值收敛为必有 JSON 值；`None` 与 JSON `null` 在唯一投影入口即跳过。
14. 删除可选 run ID、`unwrap_or_default()` 和拼接输入 ID 的伪安全路径。
15. 删除 API contract、TypeScript 生成器和前端 re-export 中的旧 run snapshot 合同。
16. 前端列表 key 直接使用稳定顺序与真实 kind，不再依赖后端派生 ID。
17. 删除固定“结构化数据”徽标及 `contentTypeLabel` 多格式映射。
18. 删除空 label 回退和覆盖 17 种历史 kind 的 `inputKindLabel`；label 只由唯一后端投影提供。
19. 删除 `value` / `text` 双通道选择函数。
20. 删除最多递归三层的 JSON 字符串自动解码。
21. 删除仅凭首尾 `{}`、`[]`、`""` 猜测 JSON 的启发式解析。
22. 删除把字面量 `\\n`、`\\r`、`\\t` 改写为控制字符的兼容转换。
23. 删除把 `\\"` 猜测为引号的旧转义修复。
24. 删除与当前 `{ stages: [...] }` 生产合同不匹配的旧“阶段数组”消息渲染分支。
25. 删除字符串/数组/对象三套 rendered prompt 分叉渲染，统一复用结构化 JSON 查看器。
26. 删除从未由后端产生的 `model` 输入分组展示分支。
27. 请求快照和原始记录直接渲染 typed JSON，不再做第二次反序列化。
28. 消息正文直接展示 JSON 解码后的真实字符串，不再经过文本修复器。
29. 更新最小投影测试，锁定四字段 JSON 合同和输入顺序。
30. 重新生成 Host TypeScript，删除旧字段和 `GenerationRunSnapshot` 接口。

## 明确保留的活跃边界

- `generation_run` 持久化字段仍为 `Option<Value>`：不同模型能力可以真实缺少某类输入；依赖图投影只输出实际存在且非 null 的值。
- `input_status` 的五种状态仍用于区分完整输入、run 无输入、缺失 run、仅结构来源和不适用，不是默认成功回退。
- `AssetGraphNode.details` 虽未由主图画布直接读取，但 generic node detail 会把它作为原始记录返回，属于隐式活跃依赖。
- GraphBuilder 的拓扑与缺失边告警继续保留在 Host 响应中，承担图构建诊断合同。
- `asset_lineage_sync` 的 `legacy_table` / `legacy_id` 仍由视频、Manga、图片和视频媒体同步主动写入，用于 canonical generation spec / media 映射；它是当前迁移边界，不是本专项可删除的旧格式兼容。
- Workflow 运行详情的 `GenerationRunSummary` 有独立 UI 与 CLI 消费者，未与本次依赖图专用死类型混删。
