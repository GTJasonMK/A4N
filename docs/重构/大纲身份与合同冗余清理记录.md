# 大纲身份与合同冗余清理记录

## 搜索覆盖范围

本专项从小说项目的分部大纲、章节大纲、生成预览、正式生成、批量生成、节奏分析和资料索引同步功能出发，按 BFS 追踪完整生产链路：

```text
OutlinesTab / OutlineAdvancedPanel / useOutlineGeneration / WritingDesk
→ frontend api/outline
→ apiInvoke / generationClient
→ Web authenticated command 或 generation route / Tauri invoke_host_command
→ Server outline dispatch、records、preview 与 generation handlers
→ Runtime outline_records 与 generation task
→ Orchestrator outline application / generation
→ project Viewer / Editor permission
→ DB part_outline / chapter_outline / chapter / workflow / project membership
→ RAG outline material index
```

横向覆盖 20 条活跃命令：分部列表与保存、正式生成启动、10 类大纲请求预览、两类最新记录删除、生成进度、章节大纲列表与保存、章节大纲更新和节奏分析。`sync_outline_materials` 虽不含重复身份字段，但它是保存、删除和生成完成后的资料索引副作用，也已纳入闭包。

隐式依赖覆盖 command manifest context/schema、Host TypeScript 生成器、Web Bearer token、Tauri 外层 `user_id`、generation route、后台 task worker、runtime config、请求预览、项目协作权限和 RAG 索引更新。仓库中没有 Outline 相关 XML DI、反射、动态代理或 AOP；动态入口仅为 Host 命令分派、generation route 和后台 task，均已纳入搜索。

## 清理前分叉

```text
Web JWT / Tauri invoke_host_command.user_id
→ Server user_id
→ Runtime / Orchestrator Viewer 或 Editor 校验

frontend api/outline
→ 20 个调用再次发送 userId
→ Server handler 从不读取该业务字段

同一请求合同
→ 前端内联 TypeScript 类型
→ Orchestrator 私有 Deserialize DTO
→ Runtime 私有更新 DTO
→ manifest opaque schema

同一响应合同
→ 前端手写进度/节奏接口
→ Orchestrator 进度结构
→ Runtime 动态 JSON 节奏结果
```

业务 `userId` 不参与项目、分部、章节大纲、任务、请求预览、节奏分析或 RAG 路径。所有权限均使用 Host 已认证身份；大纲业务范围来自 `projectId` 或 `input.project_id`。

## 清理后唯一事实标准

```text
用户身份
→ Web：Bearer token 认证出的 user_id
→ Tauri：invoke_host_command 外层 user_id

业务合同
→ Rust：a4n-api-contract::outline
→ TypeScript：generated/host.ts

业务范围
→ 顶层 projectId，或 input.project_id / part_id / outline_id

权限
→ Viewer：列表与生成进度
→ Editor：保存、更新、删除、预览、生成、节奏分析和索引同步
```

未新增旧参数兼容、默认用户、身份覆盖、权限回退、DTO 别名或 transport 适配器。
