## 搜索起点与 BFS 覆盖范围

本专项从各系统真实使用“文本 / 派生 / 自由视频”身份的功能入口出发，按广度优先顺序追踪显式调用和隐式依赖：

```text
项目列表、详情与前端路由
→ frontend 项目 API / generated Host contract
→ Runtime ProjectSummary 单查与批查
→ Orchestrator 项目读取、复制、重置、包导入导出与画布执行
→ DB 项目创建、源快照、章节来源、媒体、协作、资产血缘与画布持久化
→ SeaORM novel_project entity / ActiveModel
→ PostgreSQL baseline / 增量迁移
→ family integrity trigger 与跨表校验函数
```

横向覆盖的活跃生产场景：

- 文本项目、自由视频项目、Comic/Video/Galgame 派生项目创建。
- 项目列表、单项目详情、项目进度摘要和前端工作台路由。
- 文本、派生、自由视频三类项目复制与生成数据重置。
- 协作根项目判定、章节来源、源快照读取、媒体创建和资产血缘回填。
- 自由画布图、文本/图片/音频/视频生成、媒体上下文和视频引用。
- 项目族包、派生项目包、视频画布包导入导出及 manifest 校验。
- PostgreSQL 新库 baseline 和已有库增量升级。

清理前以 `source_mode / SourceMode / SOURCE_MODE` 为第一层，再以 `project_kind / root_project_id / source_snapshot_id`、项目创建与摘要入口、包合同和数据库对象为后续层扩展，BFS 共命中 92 个文件，其中约 66 个生产文件。显式依赖覆盖 Rust/TypeScript 字段读写、函数调用、模块导入与 `pub use`、SeaORM entity/query/transaction、Serde、JsonSchema 和生成 TypeScript。隐式依赖覆盖 Host manifest、ZIP manifest 版本、PostgreSQL function/trigger/index、migration 注册顺序和 runtime schema 门槛。

## 生产数据核验与唯一规则

开发库只读核验：

```text
comic   | derived | root=true  | snapshot=true  | 1
galgame | derived | root=true  | snapshot=true  | 1
text    | self    | root=false | snapshot=false | 47
video   | derived | root=true  | snapshot=true  | 2
identity_mismatch=0
```

因此 `source_mode` 没有独立业务信息，只是以下身份字段的重复持久化：

```text
text + root=None + snapshot=None
→ self

video + root=None + snapshot=None
→ freeform

comic/video/galgame + root=Some + snapshot=Some
→ derived

其余组合
→ 非法身份，显式失败
```

应用层唯一推导实现为 `a4n_domain::project::ProjectSourceMode::from_identity`；数据库 trigger 保留同一不变量的持久化边界校验，不再保存第二份结果。

3. 文本项目创建停止写入 `self`。
4. 自由视频项目创建停止写入 `freeform`。
5. Comic/Video/Galgame 派生项目创建停止写入 `derived`。

## 迁移与行为边界

- 迁移不会修复、猜测或回填分叉数据；发现旧列与身份字段不一致即中止。
- 迁移不可逆，不重建已删除列、索引或旧包字段。
- 不新增默认值、fallback、兼容 adapter、临时别名或占位字段。
- 历史 migration 中在最终清理前临时创建和使用旧列的 SQL 保留，以维持既有迁移执行序列；最新迁移会替换所有活跃数据库对象后删除该列。
- `generation_spec.source_context_kind=freeform` 是独立的生成上下文合同，已与项目来源模式命名解耦，不属于被删除字段。
