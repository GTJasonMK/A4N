## 已完成优化

1. `getProjectPrimaryRoute` 与 `getProjectWorkspaceRoute` 原先分别维护相同的视频、漫画、GALGame 分支；将路由选择收敛到私有 `projectRoute`，文本入口仅显式传入 `novel` / `write` 差异。
2. `projectRoutePrefetch` 原先保留 `/inspiration/` 预取分支；现行 `getProjectHomeEntryRoute` 的闭包输出只包含 `/novel/`、`/write/`、视频、漫画和 GALGame 路由，该分支无任何生产调用路径，已删除。
3. 项目列表创建完成、生命周期受限打开、项目操作“查看档案”、写作台/灵感页权限失败和详情页入口比较中的直接 `/novel/{id}` 拼接统一改为 `getProjectPrimaryRoute`。
4. 视频画布创建完成后的直接 `/video-project/{id}/studio` 拼接也改为同一 primary route，确保 freeform 视频身份只由项目路由 owner 判断。
5. 删除 `novelListUtils` 中仅转发 `PROJECT_ACCESS_ROLE_LABELS` 的 `PROJECT_ROLE_LABELS` 别名，项目列表和邀请列表直接引用权限标签 owner。
6. 将视频工作台“画布模式”动作与项目 primary route 中重复的 studio 路径拼接收敛为 `getProjectStudioRoute`；该动作仍保留独立于项目 home entry 的显式语义。
7. 蓝图确认回调删除最后一处 `/novel/{id}` 硬编码，使用已加载项目计算 primary route；项目对象缺失时显式停止确认跳转。
