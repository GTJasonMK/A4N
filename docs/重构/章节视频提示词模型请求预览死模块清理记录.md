# 章节视频提示词模型请求预览死模块清理记录

日期：2026-08-14

## 结论

章节视频提示词的“模型请求预览”并未接入前端、Host 命令、Runtime action、CLI 或任何生产工作流，7 个公开方法只被该模块自己的测试调用。该实现同时伪造片段规划、边界帧、首帧、分镜板和最终视频提示词前序输出，属于完整未使用模块、伪安全占位链和真实生成流程的第二套分叉实现。

本批整体删除该模块及专用测试，并沿依赖边清除只供它使用的片段规划预览复用查询、公共导出和日志 target。真实生产能力继续唯一地由 `start_video_generation`、`run_video_prompt_generation_task` 和 `prompt_generation/frame_prompts` 拥有；实际视频 Provider 请求预览继续由独立的 `preview_chapter_video_request` 链负责。

未新增兜底、兼容、回退、占位、适配器或第二套抽象。

## BFS 调用拓扑

```text
视频规划页按钮
  -> startChapterVideoSegmentPlan / startChapterVideoFramePrompts / startChapterVideoPrompts
  -> startVideoGeneration
  -> start_video_generation
  -> Runtime start_video_generation_typed
  -> Orchestrator run_video_prompt_generation_task
  -> prompt_generation/frame_prompts 唯一真实生成链

视频 Provider 请求预览按钮
  -> previewChapterVideoRequest
  -> preview_chapter_video_request
  -> Runtime preview_chapter_video_request
  -> Orchestrator preview_chapter_video_request_validated
  -> 实际 Provider request body

已删除的 prompt_preview
  <- 无前端入口
  <- 无 Host 命令
  <- 无 Runtime action
  <- 无 CLI 入口
  <- 仅自身 prompt_preview_flow 测试调用
```

### 入向引用闭包

- `VideoPromptRequestPreview`、`VideoPromptRequestPreviewStep`：仅模块内部、公开 re-export 和专用测试引用。
- 7 个 `preview_chapter_*_prompt_requests`：除定义外仅 `prompt_preview_flow` 测试引用。
- workflow 字符串：没有命令、路由、前端 API 或 Runtime action 使用对应预览投影。
- `ReusableSegmentPlanForPreviewQuery`、`reusable_segment_plan_for_preview`：删除主模块后无剩余调用者。
- `video_prompt_segments_with_reference_ids`：生产代码仅剩两层再导出，唯一调用来自测试自身；其内部 `video_prompt_reference_ids_for_segment` 也无其他调用者。
- `VideoExecutionIdentityMatch::Exact/Base`、base identity matcher：原调用者全部位于已删除预览链，生产路径只使用 segment identity 匹配。
