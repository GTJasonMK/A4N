## 搜索起点与覆盖范围

本专项从“在场景档案页按章节同步场景档案”功能做广度优先搜索，覆盖以下活跃调用闭包：

```text
SceneProfilesTab
→ frontend/src/api/sceneProfiles.ts
→ generated Host contract / apiInvoke / runtime config snapshot
→ Web command dispatch / Tauri invoke_host_command / CLI command manifest
→ a4n-server 任务注册、进度、取消、流式事件和命令参数解析
→ a4n-runtime 认证访问、PromptRenderer、RAG HostPort
→ a4n-orchestrator scene profile workflow
   ├─ 独立全项目同步
   ├─ 独立单章节同步
   └─ chapter analysis 内嵌单章节同步
→ 分阶段 LLM 调用及 LLM checkpoint
→ 章节完成 checkpoint / workflow 终态
→ a4n-db 场景档案、出场、转场、实体状态、证据和 generation run 事务替换
→ PostgreSQL schema / migration 约束
→ 场景档案、出场、转场 RAG 同步
```

隐式依赖检查覆盖：Cargo 模块导出与 crate 依赖、`SceneProfileSyncHostPort` 注入实现、`ChapterAnalysisHostPort` 的嵌套调用、serde/schemars 反序列化与 schema、command manifest 字符串路由、Server/Tauri/CLI 注册、runtime request scope、任务 ID/取消 token/流式进度、workflow checkpoint 查询与公开诊断 projection、Prompt registry、generation run 目标绑定、数据库事务和 migration 约束。

已核对的生产路径包括 Web、Tauri、CLI，独立全章节、独立指定章节、章节分析内嵌同步，正常完成、取消、LLM 阶段恢复、章节完成恢复和 RAG 失败路径。仓库不存在该功能对应的 XML、运行时反射、动态代理或 AOP 切面；框架隐式入口由 Host manifest、字符串 dispatch、serde schema、Prompt registry 和数据库 schema 覆盖。

28. 删除 Runtime HostPort 与 RAG 同步函数对同一 workflow trace 的双重 scope 包装。

## 保留边界

- DB `SceneSyncRecordResult` 仍用于事务内证据绑定、generation run targets 和诊断摘要，不属于未消费返回值。
- LLM 阶段 checkpoint 仍保存可重放的响应与解析结果，用于避免重复模型调用。
- 章节完成 checkpoint 仍保留，用输入指纹确认已落库章节可安全跳过。
- 任务注册、取消 token、进度与流式事件仍保留，属于活跃 Web/Tauri 执行路径。
- RAG 同步仍显式传播错误；只删除无人消费的成功统计，不添加 fallback 或吞错。

## 唯一事实标准

- Host 业务输入：`a4n-api-contract::profile::SyncSceneProfilesInput`。
- Host 外层任务与运行配置：`input/taskId/runtime_config_snapshot`。
- 认证身份：Web/Tauri 已认证调度上下文。
- 场景同步编排与恢复：`a4n-orchestrator::scene_profile::application`。
- 持久化写入结果：`a4n-db::scene_profile::SceneSyncRecordResult`，只在数据库/编排内部使用。
- 前端类型：`frontend/src/api/generated/host.ts` 生成结果。

不存在为旧 camelCase 参数、重复身份、动态成功结果、旧 checkpoint 结果载荷或假设中的外部消费者保留的兼容、回退、别名或占位路径。
