# 项目作用域认证身份与资产依赖图合同清理记录

日期：2026-08-12
编号范围：R-1864～R-1893

## BFS 搜索覆盖范围

从“用户在项目页面打开内容关联图、读取节点详情”出发，按广度优先顺序检查：

1. 前端入口：全局状态栏与小说项目操作菜单两个活跃入口，二者共用唯一 `AssetDependencyGraphDialog`；继续覆盖图布局、节点详情和项目 API。
2. 相邻 projectId-only 调用：项目状态查看/推进/预览/回退、章节列表、项目图片、蓝图资料同步和大纲资料同步。
3. Host 合同：command manifest 的 args/result schema、context fields、生成 Host 类型和 runtime config 元数据。
4. 动态 Host：Tauri `invoke_host_command`、Web `/commands/{command}` dispatch、Server 参数宏和 CLI `apply_context_args`。
5. Runtime：认证 caller、项目 Viewer gate、结果合同 re-export 和错误转换。
6. Orchestrator：`ProjectDependencyGraphApplication`、协作权限 owner 和 DB 调用边界。
7. DB：项目族 scope、全图 records/build、节点详情分派、generation input enrichment 和全部节点类型。
8. Domain/API：Rust graph/lineage DTO 与前端手写镜像类型的横向对比、Schemars/Serde 隐式生成路径。
9. 配置与隐式依赖：全仓动态 command 字符串、CLI capability、测试、脚本和文档；未发现 XML、反射、动态代理、AOP 或额外依赖注入注册。

## 活跃调用拓扑

```text
App 状态栏 / NovelDetail 操作菜单
  -> AssetDependencyGraphDialog
  -> frontend project API
  -> Web /commands/{command} 或 Tauri invoke_host_command
       caller user_id 来自 JWT / Tauri auth transport
       projectId、nodeId 来自业务参数
  -> Server command dispatch
  -> Runtime transport
  -> Orchestrator Viewer 权限 owner
  -> DB project family scope
       -> graph records -> graph builder
       -> node detail records -> generation input enrichment
  -> domain graph/lineage DTO
  -> API Contract schema -> generated TypeScript
```

两个 UI 入口是不同页面场景的快捷入口，但共用一个组件和一套 API，不是分叉实现。

## 生产与 CLI 证据

- 使用仓库现有 `target/debug/a4n capabilities describe` 确认清理前两个依赖图命令均为 opaque args/result，并要求 `userId + projectId` context；项目状态命令已由认证 transport 提供 caller，但前端仍残留第二份 `userId`。
- 使用 `a4n-postgres` 对开发库 `a4n` 执行只读事务：6 个项目（text 2、comic 1、video 2、galgame 1）、4 条项目派生、39 张生成图片、28 个生成视频、74 个 media assets，确认依赖图覆盖真实项目族和多媒体生产数据。
- Tauri 将 `user_id` 作为 `invoke_host_command` 的独立认证参数传入；Web 从 JWT 提取 caller；CLI 只根据 manifest context 注入项目作用域，因此 args 中的 `userId` 没有业务所有权。

## 唯一实现结论

- caller 身份只来自 JWT/Tauri/CLI 认证 transport。
- 项目作用域只由 `projectId` 表达；节点目标只由 `nodeId` 表达。
- Orchestrator 是依赖图权限 owner，Runtime 不再复制 Viewer gate。
- Domain 是 graph/lineage DTO 唯一事实源，DB、API Contract 与生成 TypeScript 复用同一合同。
- DB 只加载一次项目族 scope；全图与节点详情复用同一图构建路径。
