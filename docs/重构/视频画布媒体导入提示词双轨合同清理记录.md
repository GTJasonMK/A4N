# 视频画布媒体导入提示词双轨合同清理记录

日期：2026-08-16

## BFS 覆盖范围

从视频画布图片、视频、音频三个导入按钮开始，逐层追踪：

```text
VideoStudioCanvas.importMedia
→ frontend api/canvas.ts
→ import_canvas_media Host command
→ command manifest / Server dispatch / Tauri dispatch / CLI call
→ Runtime canvas_workflow/media_import
→ Orchestrator 图片导入或 Runtime 视频文件导入
→ generated_image / generated_video 与 MediaAsset 记录
```

全仓搜索了 `ImportCanvasMediaInput`、`ImportCanvasVideoInput`、
`CanvasImageImportHostInput`、`CanvasVideoImportHostInput`、
`create_imported_canvas_video_record_validated` 及全部结构体构造点。生产代码只有
`VideoStudioCanvas` 一个调用入口；CLI 仅能按 Host schema 调用，没有独立提示词工作流。
未发现 XML、依赖注入容器、反射、动态代理、AOP 或路由别名。

## 已执行清理

1. 从公共 `ImportCanvasMediaInput` 删除重复 `prompt` 字段。
2. 前端不再把 `file.name` 同时复制到 `file_name` 和 `prompt`。
3. 生成 TypeScript Host 合同同步删除该字段。
4. 图片 Runtime adapter 删除 `"导入画布图片"` 默认提示词回退。
5. `CanvasImageImportHostInput` 删除重复 `prompt` 字段。
6. 图片导入记录直接使用已经校验的源文件名作为导入标题。
7. `CanvasVideoImportHostInput` 删除重复 `prompt` 字段。
8. 删除只在 Runtime 内部使用、却错误暴露到 API 合同和前端生成类型的
   `ImportCanvasVideoInput`。
9. 删除该内部合同在类型生成器、Runtime contracts 和两层 re-export 中的公开面。
10. 视频 Host port 删除从 `CanvasVideoImportHostInput` 到旧
    `ImportCanvasVideoInput` 的逐字段复制。
11. 视频内部导入删除第二次项目编辑权限校验；唯一生产调用在进入 Host port 前已由
    `import_canvas_video_validated` 完成校验。
12. 视频记录创建删除可选提示词参数及 `"导入画布视频"` 默认回退，直接使用经过文件
    来源解析的 `source.file_name`。
13. 视频内部导入不再把完整 `generated_video::Model` 压缩为 summary。
14. Host port 不再仅凭 summary ID 二次查询刚创建的视频记录。
15. 删除二次查询附带的“刚创建的视频不存在”不可达回退分支。
16. 删除图片记录创建后再次比较 `image.project_id` 的不可达防御分支；项目 ID 来自同一
    已验证输入并原样写入记录。
17. 删除视频 Host port 返回后再次比较 `video.project_id` 的不可达防御分支；唯一 Host
    实现使用同一输入项目创建记录。
18. 删除视频记录创建时第二次查询项目及重复项目类型校验；外层应用服务已在调用 Host
    port 前完成唯一校验。

严格 Host schema 会拒绝继续发送旧 `prompt` 字段，不保留兼容别名或回退。
