# 人物立绘身份与合同冗余清理记录

## 搜索覆盖范围

本专项从人物三视图的查询、上传、主图切换、提示词生成、请求预览、单图生成、重绘、年龄变体和缺失立绘批量生成出发，按 BFS 追踪完整生产链路：

```text
CharacterPortraitsPanel / SinglePortraitDialog / UploadPortraitDialog
AgeVariantDialog / PortraitPromptDialog / MangaTab / Galgame 资产生成
→ frontend api/portrait / generationClient / apiInvoke
→ Web Bearer token / Tauri invoke_host_command.user_id
→ Server assets_and_media dispatch / generation route
→ portrait records / prompt / preview handlers / command manifest
→ Runtime portrait_records / portrait_generation / runtime config request scope
→ Orchestrator portrait application / generation task / workflow / checkpoint / prompt
→ project Viewer / Editor permission与角色档案归属校验
→ DB protagonist_profile / character_portrait / generated_image / generation_run
→ 主图切换、失败回滚、媒体引用图、文件引用清理
→ data/projects/*/portraits 文件持久化与图片 provider Host Port
→ Manga 参考资产、Galgame 表情立绘与导出下游消费
```

横向覆盖 11 条活跃命令：

1. `list_portraits_by_project`
2. `get_primary_portrait`
3. `set_primary_portrait`
4. `upload_portrait`
5. `generate_portrait_prompt`
6. `preview_generate_portrait_prompt_request`
7. `preview_generate_portrait_request`
8. `preview_regenerate_portrait_request`
9. `preview_generate_age_variant_request`
10. `preview_generate_missing_portraits_request`
11. `start_portrait_generation`

隐式依赖覆盖 command manifest schema/context/capability、Host TypeScript 生成器、generation schema、Web generation route、runtime config snapshot、Prompt 注册与模板、workflow business key、LLM/image checkpoint、依赖注入的 `PortraitGenerationHostPort`、文件回滚和 DB 事务。仓库中不存在肖像相关 XML DI、反射、动态代理或 AOP 旁路；动态入口只有 Host 命令分派、generation route 和后台 generation task，均已纳入闭包。

```

## 优化记录

1. `list_portraits_by_project` 删除重复 `userId`。
2. `get_primary_portrait` 删除重复 `userId`。
3. `set_primary_portrait` 删除重复 `userId`。
4. `upload_portrait` 删除重复 `userId`。
5. `generate_portrait_prompt` 删除重复 `userId`。
6. `preview_generate_portrait_prompt_request` 删除重复 `userId`。
7. `preview_generate_portrait_request` 删除重复 `userId`。
8. `preview_regenerate_portrait_request` 删除重复 `userId`。
9. `preview_generate_age_variant_request` 删除重复 `userId`。
10. `preview_generate_missing_portraits_request` 删除重复 `userId`。
11. `start_portrait_generation` 删除重复 `userId`。
12. 新增 `PortraitType` 唯一枚举，退役 API、前端和应用层自由字符串分叉；未知持久化值读取时显式失败。
13. `PortraitSummary.created_at` 收敛为必填字符串，删除永远不发生的 null 状态。
14. `expressions` 收敛为单一 `expression`，删除“支持多项但只消费第一项”的伪能力。
15. 参考图 ID 数组改为必填，删除缺失字段静默变为空数组的协议回退。
16. 上传 `set_primary` 改为必填，删除调用者意图缺失时的默认行为。
17. 查询、提示词、预览、上传 DTO 全部收敛到 `a4n-api-contract::portrait`。
18. Orchestrator 改为重导出正式合同，删除第二套应用 DTO。
19. 删除 `portrait/types.rs`；立绘类型描述映射只保留在提示词请求所有者中。
20. 删除原始 `create_character_portrait_record` 数据库实现及 Context 转发层。
21. 生成与上传统一使用 `create_character_portrait_for_profile`，角色档案归属校验只有一个写入口。
22. 删除 `CharacterPortraitCreateInput.is_primary` 死字段；首张主图规则只由数据库写入口决定。
23. Server 查询与写入命令统一使用严格 `{ input }`，删除手工顶层参数读取。
24. Server 五类请求预览统一使用正式 DTO 和 `strict_runtime_command_input`。
25. 删除 Server `portrait/input.rs` 手工 camelCase 解析模块。
26. 合并本地预览宏并删除只承载一个宏的 `portrait/task.rs`。
27. 年龄变体预览从 system dispatch 移回 assets/media 肖像域。
28. 11 条 manifest 命令全部改为严格 typed args 和真实 typed result。
29. 11 条 manifest 命令全部移除业务身份 context，认证身份只来自 Host。
30. `generate_portrait_prompt` 修正为即时 prompt 命令，删除不存在的 task result/reference 声明。
31. 提示词命令能力修正为 `prompt + llm`；完整立绘生成与预览修正为 `prompt + llm + image`。
32. `start_portrait_generation` 改为严格输入 schema。
33. 合并 manifest 两个重复字符串结果 schema 为 `result_string`。
34. Host TypeScript 生成器输出肖像枚举、摘要和全部普通输入 DTO，前端不再维护镜像接口。
35. generation schema 与 TypeScript 合同同步为单一 `expression`。
36. 前端五类 preview API 改为接收完整 typed input，删除位置参数和 `?? []` 拼装回退。
37. 单图生成 UI 改为单一表情输入，删除逗号拆分和数组转换逻辑。
38. 提示词对话框直接消费必填 `PortraitType`，删除“类型缺失”不可达兜底分支。
39. 立绘文件名改用稳定的 `timestamp_micros()`，删除纳秒时间不可表示时的第二套时间算法。
40. 批量生成取消路径显式记录真实错误；结果汇总删除两条默认失败文案，缺失错误改为状态不变量失败。
41. 删除 Runtime 中重复的表情规则测试，只保留规则所有者测试。
42. 新增 manifest 身份、严格 schema、typed result、domain、execution 和 capability 回归。
43. 新增前端 11 条命令统一 input envelope 且不发送 `userId` 的回归。
44. 删除请求准备结果中构造后从未读取的 `existing_count` 死字段。
45. 删除肖像手工解析退役后失活的 `optional_string_vec_field`。
46. 删除会把缺失引用 ID 静默变为空数组、且已无调用的 `optional_json_i64_vec`。
47. 删除前端已无调用的 `PortraitGenerationOperation` 二次导出。

肖像类型
→ PortraitType

立绘写入
→ create_character_portrait_for_profile

表情语义
→ expression: Option<String>
```
