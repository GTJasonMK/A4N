# 生成任务监控、恢复与取消 BFS 冗余清理记录

日期：2026-08-12
编号范围：R-2104～R-2125

## BFS 搜索覆盖范围

本专项从“查询生成任务、恢复快照、订阅进度、历史分页、取消任务”五类活跃功能入口出发，按调用边逐层扩展并闭合：

1. 前端入口：`generationClient`、`useGenerationTask`、`runGenerationProgressTask`、生成任务 store/reducer，以及章节、灵感、蓝图、优化、图片、视频、场景等页面调用者。
2. 前端 Transport：Web REST/SSE、Tauri Channel、`runtimeInvoke`/`apiInvoke`、SSE framing parser、AJV generation schema 校验、浏览器测试 harness。
3. CLI：`task get/snapshot/active/history/cancel/watch`，覆盖显式 history limit、Last-Event-ID、认证请求和取消确认。
4. Server：Axum `/generation-tasks/**` 路由、通用 Host command dispatcher、严格输入 helper、认证身份、规范错误体、SSE replay 与终态关闭。
5. Tauri：原生命令注册、订阅 registry、窗口销毁清理、Channel pump、取消命令经通用 Host dispatcher 的路径。
6. Runtime/Orchestrator/DB：generation task 授权、summary 投影、活动/历史查询、cursor 编解码、session 订阅、取消协调、checkpoint/snapshot 读取与数据库范围校验。
7. 隐式依赖：`command_manifest.rs`、generation schema/type 生成器、Host DTO inventory、Axum router、Tauri command registry、serde/schemars 注解、generation error code registry 和测试 fixtures。未发现 XML、反射、动态代理、AOP 或第二套 DI 容器。

## 清理前调用拓扑

```text
Pages / hooks / store
  -> generationClient
     -> Web REST/SSE
        -> Axum generation routes
     -> Tauri Channel + generic Host command
        -> native command registry / Server dispatcher
  -> Runtime generation_tasks
       -> duplicated cancel facades
       -> unused summary facade/helper
       -> renamed DB cursor alias + re-exported defaults
  -> Orchestrator summary/session/cancel
  -> DB checkpoint/snapshot/history

Generation schema / command manifest / browser harness
  -> oversized subscription response
  -> opaque cancel contract
```

横向对比结论：REST/SSE 与 Tauri Channel 是 Web、桌面两种宿主所需的不同 Transport，不能合并；订阅 registry、窗口销毁清理、destructive lifecycle coordinator 是资源与数据安全边界，必须保留；`get_generation_progress` 是大纲生成统计，不是通用 generation task 的旧实现。

## 清理后调用拓扑

```text
Pages / hooks / store
  -> generationClient + generated generation contracts
     -> Web REST/SSE（显式 limit、严格事件类型、规范错误）
     -> Tauri Channel（最小 subscription_id）
        -> generic Host bridge 注入桌面 user identity
  -> strict typed Host cancel command
  -> Runtime generation_tasks（唯一 cancel / summary / history facade）
  -> Orchestrator 唯一授权、summary、订阅与取消规则
  -> DB 唯一 cursor 类型、history 上限和 checkpoint/snapshot 数据源
```

## 唯一实现结论

- 生成任务取消只有一个 Runtime facade 和一个 Orchestrator 状态协调实现。
- history cursor 的内部事实类型只有 DB `GenerationTaskListCursor`；外部仍只暴露签名字符串 cursor。
- Host cancel 输入/输出只有 API Contract 一套，前端不发送第二份身份字段。
- subscription 创建与关闭共享同一个只含 `subscription_id` 的资源句柄合同。
- history 默认值已删除；调用者显式决定分页大小，DB 维护唯一上限。
- 非规范 Host 错误和未知 SSE 数据事件均显式失败，不再伪装或静默忽略。
