# 章节分析模型请求预览冗余清理记录

日期：2026-08-14

## 结论

章节分析、继续同步和导入分析的请求预览已收敛为同一条真实请求构造链：只展示基于当前持久化状态能够精确构造、且真实执行路径会使用的请求。删除空 facts、空阶段结果和 `blocked` 状态组成的伪预览，不再用占位数据模拟尚未发生的模型输出。

本批复用既有 `a4n_prompt::chapter_analysis::ChapterAnalysisRequestStep` 作为唯一请求步骤结构，没有新增兜底、兼容、回退、占位或第二套通用预览抽象。

## 优化记录

1. 删除空 facts 预览 JSON，禁止以空角色、事件和伏笔数组冒充真实前序输出。
2. 删除 `preview/placeholders.rs`。
3. 删除只负责拼接事实阶段的 `preview/steps/facts.rs`。
4. 删除用占位 facts 构造后三阶段的 `preview/steps/derived.rs`。
5. 删除二次汇总步骤的 `preview/steps.rs`。
6. 删除旧章节分析预览 facade `preview.rs`。
7. 删除 `build_chapter_analysis_preview_requests` 公开出口。
8. 删除只服务伪预览的 `build_chapter_analysis_requests` 数据库 facade。
9. 新分析预览直接复用真实 `build_chapter_fact_extraction_request`。
10. 将首个请求的 key、title、prompt 名称收敛到 `build_chapter_analysis_initial_request` 一处。
11. 复用既有 `ChapterAnalysisRequestStep`，删除 `ChapterAnalysisPreviewStep` 重复类型。
12. 删除新分析预览中的物体发现 `blocked` 占位。
13. 删除分析保存前构造的角色发现请求；该请求使用的是旧持久化状态，并非真实后续请求。
14. 删除新分析预览中的四个场景同步 `blocked` 占位。
15. 删除新分析预览中的角色同步 `blocked` 占位。
16. 删除 `blocked_preview_step` 通用占位工厂。
17. 删除 `blocked_scene_preview_steps` 场景占位集合。
18. 删除专门验证占位数量的测试。
19. 继续同步预览读取真实工作流 checkpoint，只进入首个未完成的模型阶段。
20. 物体发现已完成时不再重复展示物体发现请求。
21. 角色发现已完成时不再重复展示角色发现请求。
22. 场景同步已完成时不再重复展示场景候选请求。
23. 继续同步不再展示依赖未来模型返回值的角色同步伪请求。
24. 场景预览删除 occurrences、transitions、entity states 三个 `blocked` 占位。
25. 场景预览删除可变 `ready_state` 参数；真实请求状态固定由 Runtime 标记为 `ready`。
26. 场景预览删除 `ready_note` 参数和复制逻辑。
27. 删除 `SceneProfileSyncPreviewStep` 重复中间类型，直接返回统一步骤结构。
28. 收窄场景预览方法为 crate 内部能力，不再作为无调用公共 API 暴露。
29. 导入分析预览从“每章四个伪请求”改为“每章一个真实首请求”。
30. 删除导入分析末尾的角色发现/角色同步 `blocked` 占位。
31. 导入分析预览容量从 `章节数 * 4 + 1` 修正为真实章节数。
32. Runtime 映射改为必有 prompt 名称、必有 request、固定 `ready`，不再接受本路径的空请求状态。
33. 新分析预览复用 Runtime 已完成的权限和章节校验结果，删除紧邻的 Orchestrator 重复预检。
34. 清理提示词注册表中已不存在的 `ChapterAnalysisService.*` 调用方别名。
35. 提示词 `used_by` 改为当前唯一真实请求构造函数。
36. 增加防回归测试，断言预览只构造事实抽取请求且不包含 `preview_note`。
