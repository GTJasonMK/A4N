# 视频媒体文件身份与缓存时间回退冗余清理记录

日期：2026-08-15

## BFS 覆盖范围

本批从四组活跃生产功能出发，按 BFS 追踪文件身份、输出路径和缓存时间的完整调用闭包。

```text
章节视频 / 画布视频 / 参考媒体视频生成
→ Provider 图片输入解析
→ canonicalize_data_file_path
→ image_file_to_remote_temp_media_url
→ TempMediaUploadRequest
→ Server 临时媒体上传路由

视频画布导入 / 章节上传 / 参考媒体上传 / 成片插入 / 后处理上传
→ Runtime video_records imports
→ uploaded_video_source / import_video_source
→ 视频探测、记录创建与媒体绑定

VideoStudioCanvas.importMedia(image | audio)
→ import_canvas_media Host command
→ Runtime canvas_workflow adapter
→ Orchestrator 图片 / 音频持久化
→ generated_image / media_asset

assemble_chapter_videos / load_cached_assembled_chapter_video_preview /
push_assembled_chapter_video / Runtime 启动恢复
→ assembly_request_context
→ 成片输出与 manifest 路径
→ 缓存新鲜度、过期扫描
→ cleanup outbox
```

已全仓搜索相关函数、模块、固定回退值、Host command、command manifest、Server 分发、
Runtime 启动入口、Orchestrator Host Port、媒体合同、文件写入者、缓存消费者和测试引用。
`assembly/cache/paths.rs` 中两个函数都只有 `assembly_request_context` 一个生产调用者；
远端参考图和导入视频的文件名最终都进入严格字符串合同或持久化来源字段，不能用伪造名称代替。
仓库中未发现对应 XML、依赖注入容器、反射、动态代理、AOP 或其他隐藏入口。

## 优化记录

1. 删除远端参考图文件名缺失时伪造 `video-input.png` 的回退，非 UTF-8 或空文件名改为显式错误。
2. 删除视频路径导入时伪造 `video` 来源文件名的回退，无法取得真实 UTF-8 文件名时显式失败。
3. 删除单调用 `assembled_video_output_path` 包装函数。
4. 删除该包装函数永远只返回 `Ok` 的无效 `Result<PathBuf, String>`。
5. 删除单调用 `assembly_cache_manifest_path` 包装函数。
6. 删除 manifest 路径无法取文件名时伪造 `assembled.mp4` 的回退。
7. 删除失去全部实现与消费者的 `assembly/cache/paths.rs` 模块及 re-export。
8. 成片输出和 manifest 路径在唯一 owner `assembly_request_context` 中直接由标准库 `join` 与 `with_extension` 生成。
9. 删除上传视频临时文件时间戳从纳秒静默降级到微秒乘算的回退，无法表示时显式失败。
10. 删除画布导入图片时间戳从纳秒静默降级到微秒乘算的回退，无法表示时显式失败。
11. 删除画布导入音频时间戳从纳秒静默降级到微秒乘算的回退，无法表示时显式失败。
12. 删除成片缓存时间晚于当前系统时间时仍判定“新鲜”的回退，改为返回明确时钟错误。
13. 删除上传视频临时文件恢复在无法计算过期边界时使用 `UNIX_EPOCH` 的回退，记录错误并停止本次扫描。
14. 删除成片缓存恢复在无法计算过期边界时使用 `UNIX_EPOCH` 的回退，记录错误并停止本次扫描。
15. 删除成片缓存修改时间早于 `UNIX_EPOCH` 时使用版本 `0` 的回退，改为显式扫描错误。

合法文件名、正常系统时间、现有成片命名格式、缓存 TTL、视频探测、媒体持久化和 cleanup
outbox 行为不变。未新增 fallback、兼容、回退、占位逻辑或第二套路径实现。
