# 认证退出当前会话命令别名清理记录

日期：2026-08-12
编号范围：R-1699～R-1718

## BFS 搜索覆盖范围

从“退出当前登录会话并清理本地凭证”功能入口逐层广度优先展开：

1. 前端入口：Zustand AuthStore、`api/auth.ts::logoutUser`、`apiInvoke` Web/Tauri 路由、本地认证存储的 finally 清理。
2. CLI 入口：`auth logout`、`ApiClient::logout`、环境变量凭证写保护、Server 失败后本地凭证清理、routing special request。
3. Host/REST 注册：command manifest 的 `logout_user`、生成 Host 清单、Tauri command registry、Server `/auth/logout` 和 `/commands/{cmd}`。
4. 应用链路：Runtime `logout_user`、Orchestrator `logout_user_session`、`required_logout_identity`、DB 会话撤销。
5. 横向对比：`logout_user` 与上一批已收敛的 `revoke_session` 都接收当前 session ID、撤销同一用户会话并返回 unit；差异仅在客户端随后清理本地凭证。
6. 隐式依赖：Serde/Schemars、Host TypeScript 生成、Tauri command 宏、Axum route table、CLI 路由表、动态命令字符串、Bearer 认证和本地配置锁。

搜索未发现 XML、反射注册、动态代理、AOP 切面或依赖注入容器配置。生产环境中的 Web、Tauri 和 CLI 都已持有当前 session ID，因此 Server 端 `logout_user` 是 `revoke_session` 的完整命令别名，不承载独立业务规则。

## 唯一实现结论

- Server 会话撤销能力仅剩 `revoke_session`。
- Web/Tauri/CLI 均通过 `/commands/revoke_session` 或同一 Tauri Host dispatcher 进入 Runtime/Orchestrator/DB 唯一实现。
- “退出”只保留为客户端行为名称：调用撤销当前 session 后，在 finally/请求结束后清理本地凭证。
- 不再存在 `/auth/logout`、Tauri `logout_user`、Runtime/Orchestrator logout 包装或 Option 身份校验链。
