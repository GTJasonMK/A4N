日期：2026-08-12

## BFS 搜索覆盖范围

从首页“导出项目 / 导入项目”功能出发，按广度优先顺序检查：

1. 前端入口：文本项目、派生项目、freeform 视频项目的导出操作，项目导入对话框、文件选择器、导入完成后的资料同步。
2. 前端 API：项目族导出、派生项目导出、项目族导入、视频画布导出、视频画布导入，以及旧完整文本项目 JSON 导入。
3. Host 合同：command manifest、项目包 DTO、生成 TypeScript、文件输入输出能力、CLI capability schema。
4. 动态 Host：Web Server dispatch、Tauri 通用 `invoke_host_command`、CLI `call/capabilities`；未发现第二套路由表或命令别名。
5. Runtime：上传文件名/Base64 校验、项目族与视频画布 ZIP 适配、sidecar package I/O、媒体文件写入与回滚。
6. Orchestrator：项目族/派生/视频画布导入导出 application、Owner 权限、manifest 校验、包组装、媒体导入回滚。
7. DB：项目族导出 selection/rows、项目族导入、视频画布导入，以及旧文本项目 JSON 的专属解析后落库链。
8. 包格式与隐式依赖：ZIP manifest 路径、版本、mode、生成类型、测试、文档和全仓动态命令字符串。
9. 框架配置：未发现 XML、反射注册、动态代理、AOP、额外依赖注入容器或隐藏路由依赖。

残留搜索中的 `ProjectTextImportDialog` / `importTextProjectId` 是“向现有项目导入正文材料”的活跃功能，不是已退役的完整项目 JSON 备份恢复链，予以保留。

## 清理前调用拓扑

```text
项目族 / 派生项目导出
  -> NovelList.handleExport
  -> frontend project API（重复发送 caller userId）
  -> Web/Tauri Host
  -> Runtime family_api
  -> HostPort.verify_project_owner
  -> Runtime access helper
  -> Orchestrator.verify_project_permission
  -> Orchestrator 再读取项目 + DB export selection 再读取项目
  -> project family package -> ZIP

freeform 视频项目导出
  -> 同样经过 Runtime HostPort Owner 权限回环
  -> video studio package -> ZIP

任意 .zip 导入
  -> 先尝试项目族包
  -> 任意错误后再尝试视频画布包
  -> 真实项目族导入错误可能被误判为包类型错误

旧 .json 完整文本项目导入
  -> import_project_full_upload
  -> Runtime UTF-8/JSON 解析
  -> Orchestrator text_import_payload 映射
  -> DB text_import 专属事务写入
  -> 章节后处理失败只记录 warn，导入仍返回成功
```

## 唯一包格式

- 项目族/派生项目：manifest `a4n-project-family.json`，version `project_family_v1`，mode `project_family` / `derived_project`，文件后缀 `.a4n-family.zip`。
- 视频画布项目：manifest `a4n-video-studio-project.json`，version `video_studio_project_v1`，文件后缀 `.a4n-video-studio.zip`。
- 两类上传共用唯一 `ImportProjectPackageUploadInput`，但通过不同后缀和内部 manifest 严格选择唯一命令。
- 不保留旧 `.a4n-project.zip`、通用 `.zip` 猜测、旧 `.json` 备份或异常回退兼容。

```text
       family suffix -> family command

```

## 唯一实现结论

- caller 身份只来自认证 transport，项目包 API 不再接受第二份 `userId`。
- 同一种上传载荷只有一个 DTO；同一种包格式只有一个后缀、一个 manifest 和一个命令。
- 前端不再通过捕获业务错误猜测包类型。
- Orchestrator 是 Owner 权限唯一 owner，Runtime HostPort 只负责包与媒体 I/O。
- 完整文本项目恢复只保留项目族 ZIP 新实现；旧 JSON 兼容链已整条删除。
- 媒体写入回滚是数据完整性保护，继续保留且没有增加兼容或静默成功路径。
