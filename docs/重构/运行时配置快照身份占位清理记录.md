# 运行时配置快照身份占位清理记录

## 搜索覆盖范围

以 Web/Tauri 的 buildRuntimeConfigSnapshot 为 L0 起点，按 BFS 覆盖本机配置存储与正整数 ID 校验、HTTP command/generation 入口、snapshot_from_args 反序列化、task-local snapshot、LLM/Image/Video/Embedding 配置选择、连接测试身份校验及四类数据库模型投影。生产快照创建路径均携带正整数配置 ID；未发现依赖缺失 ID 或 -1 身份的活跃路径。

## 优化记录

1. RuntimeConfigSnapshot.schema_version 从可选字段改为必填版本，删除缺失版本仍按当前合同执行的兼容路径。
2. LLM、Image、Video、Embedding 四类运行时配置 ID 从 Option<i64> 收敛为必填 i64。
3. 删除四处 id.unwrap_or(-1) 占位身份；运行时模型只保留快照提供的真实配置 ID。
4. schema 版本与配置 ID 约束下沉到 RuntimeConfigSnapshot 的 Serde 合同，所有反序列化路径统一拒绝错误版本及零或负数配置 ID。
5. 配置 ID 查找删除 Some(id) 包装比较，直接按唯一数值身份匹配 active 配置和配置列表。
