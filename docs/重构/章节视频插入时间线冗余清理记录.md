# 章节视频插入时间线 BFS 冗余清理记录

日期：2026-08-11
编号范围：R-1412～R-1428

## 搜索起点与覆盖范围

以“用户在章节视频片段之间补充一个镜头，并进入成片预览、排序和装配”为功能起点，按 BFS 检查：

1. 前端入口：`VideoTab`、片段配置侧栏、插入片段面板、成片工作区、视频 API 和加载聚合器。
2. Host 合同：`VideoGenerationOperation` 的 Serde tagged enum、generation schema、生成 TypeScript、command manifest 和生成 Host 命令表。
3. Host 实现：Web Server dispatch/handler；Tauri/Web 共用的命令合同与 Runtime action 导出。
4. Runtime/Orchestrator：视频 generation worker 分派、视频 prompt actions、记录写入、成片上传、排序、预览、推送和装配规则。
5. Core/DB：无 IO 时间线规则、三个 SeaORM entity、`chapter_video_prompt`/`generated_video` 绑定字段、workflow/task/generation 运行记录。
6. 隐式配置：Prompt registry、Schemars/Serde 生成合同、迁移注册顺序和 Runtime 必需 schema marker。
7. 历史迁移：保留已部署的 `chapter_video_timeline` 与 `chapter_video_timeline_cleanup` marker，检查新库 baseline 与历史库顺序。
8. 横向实现：对比提示词时间线与 `generated_video.metadata_json.assembly_insert`；后者已完整覆盖上传、起始/锚点定位、移动、排序、预览、分段推送和最终装配。
9. 框架检查：未发现 XML、反射、动态代理或 AOP 入口；动态入口只来自 Serde enum、command manifest、Server dispatch、Prompt registry 和 migration registry。

## BFS 结论与调用拓扑

提示词时间线表面链路为：

```text
VideoTab / InsertedSegmentTimelinePanel
  -> generated Host API
  -> command manifest
  -> Server video dispatch / handler
  -> 不存在的 Runtime action

VideoGenerationOperation::PromptInsertedSegment
  -> generation reservation/session
  -> 通用 worker 分派
  -> 无专用 worker，进入错误路径
```

三个旧实现文件在 Git 基线中本来就未注册进模块树，属于完整孤儿代码，不恢复：

- `crates/a4n-db/src/video/timeline.rs`
- `crates/a4n-orchestrator/src/video/timeline.rs`
- `crates/a4n-orchestrator/src/video/prompt_generation/frame_prompts/inserted_segment.rs`

唯一活跃实现为：

```text
VideoAssemblyWorkspace
  -> upload/update assembly insert
  -> Runtime video records
  -> Orchestrator assembly clip rules
  -> generated_video.metadata_json.assembly_insert
       sort_order
       insert_after_video_id
       insert_after_shot_number
  -> cached preview / segmented push / final assembly
```

原生章节视频顺序由同一成片规则读取 `generated_video.metadata_json.shot_number`；不再依赖第二套时间线镜像。

## 生产数据证据

- 对现有开发库执行只读审计：1 条 timeline、15 条 native 镜像 item、1 条 event；inserted item、prompt 绑定、video 绑定均为 0。
- 开发库有 1 条 `video_inserted_segment` workflow，无正式插入片段产物；15 条 native 镜像均可由共享 segment plan 重建。
- 测试库 timeline、item、event、prompt/video 绑定均为 0。
- 两个历史时间线迁移均已记录为已执行；因此保留历史 migration marker，并在最后追加不可逆 retirement migration。
- retirement migration 在删除 schema 前显式拒绝任何已提交 inserted item 或 prompt/video 绑定，不静默转换为 `assembly_insert`，也不丢弃未知正式数据。

## 当前事实标准

章节成片补充镜头只保留 `assembly_insert`：位置与顺序由 `generated_video.metadata_json.assembly_insert` 表达，原生视频由 `metadata_json.shot_number` 排序，二者进入同一 Orchestrator 成片规则、预览、推送和装配路径。代码库不再公开提示词时间线、插入草稿 worker、时间线 DTO、命令、UI、Core 规则、SeaORM entity 或持久化绑定字段。
