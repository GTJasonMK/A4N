## 发现

`a4n-db::project_family_import::ImportIdMaps.media_binding_ids` 只有两处源码引用：

- `ImportIdMaps` 中的字段声明；
- 导入媒体绑定时把新行 ID 写入该 map。

全仓没有读取、导出、JSON 序列化或后续 remap 使用。媒体绑定的活跃依赖只有 `media_asset_id` 和按 `target_kind` 解析后的 `target_id`；数据库自增 `media_binding.id` 不被其他包记录引用。

## 已执行清理

1. 删除 `ImportIdMaps.media_binding_ids`。
2. 媒体绑定导入由 `insert_mapped_import_rows!` 收敛为 `insert_import_rows!`，保留完整数据库插入和所有资产/目标 ID remap。
3. 未删除包中的 `media_bindings` 行、`id` 字段、唯一性校验、业务校验、索引或数据库触发器。

清理后的唯一事实标准：

```text
media_binding.media_asset_id → media_asset_ids
media_binding.(target_kind, target_id) → 对应目标实体 ID map
media_binding.id → 数据库新生成的本地身份，不进入跨行 remap
```

未新增兼容、默认、回退、吞错或占位逻辑；包合同和运行时行为保持不变。
