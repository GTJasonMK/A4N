# 主题身份与启动应用冗余清理记录

## 搜索覆盖范围

本专项从应用启动和设置页的主题功能出发，按 BFS 追踪完整生产链路：

```text
App 启动 / 全量配置导入 / 主题设置页
→ loadAndApplyActiveTheme / useThemeTabController
→ frontend api/theme
→ apiInvoke
→ Web command request / Tauri invoke_host_command
→ Server theme dispatch 与 routes
→ Runtime theme actions
→ Orchestrator theme ownership validation
→ DB theme_config
```

横向覆盖主题列表、创建、更新、删除、激活、导入、导出和全量配置导入后的主题重载。隐式依赖覆盖 command manifest 的 context/schema、Web access-token 自动刷新、Tauri 外层认证用户参数、`THEME_APPLIED_EVENT`，以及 Relationships 和 Asset Graph 的事件监听器。仓库中没有主题相关 XML DI、反射、动态代理或 AOP；动态分派仅为 manifest 命令名和 Web/Tauri Host 路由，均已纳入闭包。

## 清理前分叉

```text
Web JWT / Tauri Host user_id
→ Server 认证上下文 user_id
→ Runtime / Orchestrator 权限校验

前端主题业务参数
→ 7 个命令再次发送 userId
→ command manifest 默认 USER_CONTEXT 再声明 userId
→ Server theme handler 不读取该业务参数
```

同一请求存在两个用户身份来源，而生产权限链只使用 Host 认证身份。应用启动还会在 HTTP 模式缺少 access token 时静默清空主题并跳过请求，即使 refresh token 与 session 足以通过 `apiInvoke` 自动刷新。主题应用事件携带的 mode 详情没有任何消费者。

## 优化记录

1. `listThemes` 删除无效 `userId` 参数，只发送空业务参数。
2. `createTheme` 删除重复 `userId`。
3. `updateTheme` 删除重复 `userId`。
4. `deleteTheme` 删除重复 `userId`。
5. `activateTheme` 删除重复 `userId`。
6. `exportTheme` 删除重复 `userId`。
7. `importTheme` 删除重复 `userId`。
8. 删除 `frontend api/theme` 对 `requireCurrentUserId` 的零剩余依赖。
9. 主题设置页改为调用唯一的无身份参数列表合同。
10. 7 个主题 command manifest 条目统一改为 `NO_CONTEXT`，不再生成业务 `userId`。
11. 列表命令沿用严格空参数 schema；激活、删除和导出命令拒绝额外字段。
12. 创建和导入命令改用既有 `strict_typed_input_schema`，不新增主题专用 schema helper。
13. 更新命令的外层 schema 改为拒绝额外字段。
14. 删除启动主题加载对 access token 的静默跳过，统一进入 `apiInvoke` 的现有 refresh-token 链路。
15. `selectActiveTheme` 只接受已认证的明确用户 ID，删除内部可空分支。
16. 删除 `ThemeAppliedDetail` 和无人读取的 CustomEvent detail，保留无载荷状态变更事件。
17. 新增一项最小前端合同回归，一次验证 7 个主题 API 都不再发送 `userId`。
18. 新增一项 manifest 回归，一次验证 7 个命令只使用 Host 认证身份并拒绝退役字段。

## 清理后唯一事实标准

```text
用户身份
→ Web：认证 JWT 提取的 user_id
→ Tauri：invoke_host_command 外层 user_id

主题业务参数
→ 只保留 input / themeId

启动认证恢复
→ apiInvoke 统一负责 access token 与 refresh token

主题应用通知
→ 无载荷 THEME_APPLIED_EVENT
```

未新增身份兼容字段、旧参数适配器、默认用户、主题加载回退或事件载荷占位。
