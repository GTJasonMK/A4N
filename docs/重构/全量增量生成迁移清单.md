## 3. 关闭裁决

1. 旧合同类别 `llm_full_response/service_task_event/legacy_sse_progress/frontend_workflow_event` 均为 0，并由 `check-generation-cutover-boundary.sh` 阻止复活。
2. `manual_stream_collector` 的两个匹配不是待删除领域 collector：`stream_collect.rs` 是共享 LLM 完整响应 adapter；`rag_ingest/sync/batch.rs` 汇聚 embedding 并发任务。Orchestrator/Runtime generation 领域 collector 扫描为 0。
3. `structured_stream` 的 11 行只负责共享 raw collection、严格 parse/schema repair 或领域调用，不分配 generation sequence，不发布 terminal，不拥有 Host transport。
4. `media_provider_job` 的 23 行按边界分别归属 video application、纯规则、Runtime job lifecycle、provider Host port 和 sidecar adapter；页面轮询、第二 provider cleanup loop、第二 outbox/worker 均不存在。
5. 当前清单所有 active 行均已 `closed-canonical`。这只关闭阶段 0/10 的入口归类要求，不替代远端 paid provider/artifact、远端 Actions、全 workspace、发布级 IG-VERIFY 或跨平台 CI 证据。
