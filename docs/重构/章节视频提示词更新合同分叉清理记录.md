# 章节视频提示词更新合同分叉清理记录

日期：2026-08-12
编号范围：R-1600～R-1615

## BFS 搜索覆盖范围

从“保存章节视频提示词”功能入口逐层广度优先展开：

1. 前端入口：`useVideoRecordActions.ts` 的保存、优化、删除操作，`api/video/prompts.ts`，生成的 Host 类型，以及 `video-mode-switch` E2E 动态命令桩。
2. Host 入口：API command manifest、Server `dispatch/video.rs`、`media/video_prompt.rs`，以及 Tauri 唯一通用入口 `invoke_host_command`。
3. Runtime：`actions/video_prompts.rs` 的查询、更新、优化、删除和下游媒体清理端口。
4. Orchestrator：`video/prompt_application.rs`、`prompt_optimization.rs`、`context/video.rs`、`video/mod.rs`，覆盖权限、来源门禁、下游冲突策略、元数据同步和优化写回。
5. DB：`video_prompt.rs`、`update/policy.rs`、`update/checkpoint.rs` 及测试，覆盖事务更新、生成运行检查点和持久化 Patch。
6. 隐式依赖：Serde 非空/可空更新字段规则、Schemars/TypeScript 生成、命令字符串动态分发、`DownstreamConflictStrategy` 枚举，以及 E2E 对 wire payload 的校验。

横向对比确认存在三套容易混淆的对象：API wire 更新 DTO、Orchestrator 重复 wire DTO、DB 持久化更新对象。前两套服务同一 Host 业务且行为不一致；DB 对象是内部字段 Patch，不应伪装成第二套 Host DTO。

## 唯一实现结论

- Host wire 输入：`a4n-api-contract::video::{UpdateChapterVideoPromptInput, OptimizeChapterVideoPromptInput}`。
- Host wire 输出：`a4n-api-contract::video::ChapterVideoPromptSummary`。
- 内部持久化：`a4n_db::video_prompt::ChapterVideoPromptPatch`。
- 桌面与 Web：共同经过 Server command dispatcher；不保留第二套专用命令适配器。
