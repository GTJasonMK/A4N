# 角色与场景证据锚点 BFS 冗余清理记录

日期：2026-08-11
编号范围：R-1410～R-1411

## 搜索起点与覆盖范围

分别以“AI 发现角色并绑定首次出场证据”和“AI 同步场景档案、出场、位移及实体状态证据”为入口，按 BFS 检查：

1. Prompt 与请求合同：角色发现 prompt/request 中唯一 `evidence_anchor_id`，场景同步请求中的 `evidence_anchor_ids`/`source_anchor_ids` 和 text-anchor 候选。
2. 流式解析：角色发现 output parser；场景 profile/occurrence/transition/entity-state 四类 parser。
3. Canonical 校验：JSON object allowlist、正整数 anchor ID、候选集合归属、角色/物体 ID 引用和枚举值校验。
4. 派生与持久化：anchor quote/chapter 解析、角色首次/最近出场章节、场景 evidence 文本及 DB evidence 绑定。
5. 测试与横向搜索：全仓检查旧 `evidence`、`evidence_span_id`、`source_text`、`original_text`、`source_span_ids`、`evidence_span_ids` 在这两条功能链中的生产者和消费者。
6. 框架入口：模型调用由 Orchestrator 直接拥有；未发现 XML、反射、动态代理、AOP 或其他 schema 绕过 parser。

## 活跃调用拓扑

```text
character discovery prompt
  -> strict JSON parser + field allowlist
  -> evidence_anchor_id lookup
  -> derived chapter/evidence
  -> character profile + text-anchor evidence binding

scene profile sync prompt
  -> four strict JSON parsers + per-object allowlists
  -> canonical anchor ID lookup
  -> scene drafts/evidence refs
  -> transactional scene persistence
```

## 优化记录

- R-1410：角色发现 parser 已由字段 allowlist 严格拒绝所有非合同字段；删除只为两个旧字段定制报错的 deprecated helper 调用和两条兼容历史测试，保留统一未知字段拒绝与 canonical anchor 校验。
- R-1411：场景同步四类 parser 均已有各自完整字段 allowlist；删除重复的五旧字段黑名单 helper、四个调用点和 re-export，旧字段继续由统一 allowlist 显式失败。

## 当前事实标准

模型输出只接受当前 prompt 声明的 anchor ID 字段。旧自由文本或 span 字段没有转换、别名、专用兼容报错或回退；所有非合同字段统一由 object allowlist 拒绝，随后只从 canonical text anchor 派生证据文本和章节。
