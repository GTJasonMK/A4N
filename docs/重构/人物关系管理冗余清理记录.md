## 事实边界结论

以下三类数据不是重复实现，保留各自唯一职责：

1. `blueprint_relationship`：故事规划事实，服务蓝图生成、精炼、版本和导入导出。
2. `protagonist_profile.social_attributes`：当前正式角色事实，可由蓝图播种并随正文演化。
3. `attribute_event(category=social)`：按章节记录关系变化的时间线事实。

蓝图同步仅补充缺失关系，不覆盖已有角色事实；章节事件负责演化而不是重写蓝图。因此没有删除上述任一数据层。

## 优化记录

1. 使用仓库已安装的 `@xyflow/react` 替换自研 Canvas 关系图渲染器。
2. 删除自研力导向迭代布局，改为确定性的中心/同心环初始布局。
3. 删除 Canvas DPR、尺寸监听和手工重绘生命周期。
4. 删除网格绘制、主题色读取、调色板和主题事件重绘。
5. 删除节点与边的手工命中检测。
6. 删除二次曲线采样、线段距离和自环几何计算。
7. 删除手工箭头绘制。
8. 删除手工节点拖拽状态机与 pointer capture 管理。
9. 删除手工画布平移、缩放和坐标变换。
10. 删除节点标签避让、矩形碰撞和 Canvas 文本截断。
11. 复用 React Flow 的节点拖拽、边点击、缩放、平移、fit view、Controls 和 Background。
12. 删除关系图节点中从未被消费的 `profileId`。
13. 删除边模型中替换后不再使用的 `parallelCount`。
14. 删除布局载荷中从未读取的 `schema_version`。
15. 删除布局载荷中从未读取的 `updated_at`。
16. 删除无生产者的“裸 positions”兼容读取，只接受实际写入的 `{ positions }` 合同。
17. 删除布局读写的静默 catch；损坏合同和存储失败现在显式报错。
18. 保留现有归一化节点坐标，使既有项目布局继续使用同一真实格式。
19. 将“时间线是否开始”收敛到后端 `timeline_started`，覆盖同步章节号和五类时间线记录。
20. 将“初始档案是否可编辑”收敛到后端 `initial_profile_editable`，统一项目生命周期、同步进度和时间线记录门禁。
21. 删除关系页和角色详情页各自基于 `last_synced_chapter` 的不完整规则复制。
22. 列表查询以固定五次批量查询收集时间线 profile ID，避免按角色 N+1 查询。
23. 删除 `frontend/src/api/character/*` 中重复传递的当前 `userId`；身份仅由 Tauri Host 参数或 HTTP Bearer token 注入。
24. 将 character typed-input Web 命令改为 strict envelope，旧 `userId` 等未知参数不再被静默忽略。
25. 将视频画布专用名称的 Controls 样式收敛为关系图与视频画布共用的 `a4n-flow-controls`。
26. 新增最小回归检查，固定角色 API 不再发送 `userId`，并覆盖完整初始档案门禁真值表。
27. 统一 character typed-input 的路由与命令清单：无运行时配置的命令只接受 `input`，需要请求级配置的命令只额外接受 `runtime_config_snapshot`。

## 行为变化

- 关系图视觉布局从运行时力导向计算改为确定性同心环；用户拖拽、缩放、平移、边详情、角色侧栏和布局持久化仍保留。
- 已存在的 `{ positions, schema_version, updated_at }` 数据仍按唯一的 `positions` 字段读取；后续只写 `{ positions }`。
- 手工创建过章节事件但 `last_synced_chapter` 仍为 0 的角色，现在正确进入章节时间线入口，不再先显示可编辑再由数据库拒绝。
- 非活动项目、结构化关系和已开始时间线的关系分别显示对应限制原因。
- 角色 API 的调用者身份只有一个来源；Web typed-input 路由不再接受退休的身份参数。
