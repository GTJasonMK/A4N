# 自由画布身份合同冗余清理记录

## 搜索覆盖范围

本专项从自由画布的图编辑、节点预览与执行、文本资产保存和媒体导入功能出发，按 BFS 追踪完整生产链路：

```text
VideoStudioCanvas / canvasGraphMapping
→ frontend api/canvas
→ apiInvoke
→ Web Canvas dispatcher / Tauri invoke_host_command
→ Server canvas handlers
→ Runtime canvas_workflow
→ Orchestrator Canvas 权限与执行
→ DB canvas / workflow / media / project membership records
```

横向覆盖 8 条活跃命令：画布图读取、节点合同读取、画布图保存、文本资产保存、节点请求预览、画布图执行、单节点执行和媒体导入。`runCanvasGraph` 与 `runCanvasGraphToNode` 共用 `run_canvas_graph`，因此前端共清理 9 处重复字段。隐式依赖覆盖 command manifest context/schema、生成 Host 类型、自定义 Web Canvas 分派、Web Bearer token、Tauri 外层 `user_id`、后台 workflow、runtime config、媒体导入，以及图像/视频生成 Host port。仓库中没有 Canvas 相关 XML DI、反射、动态代理或 AOP；动态入口仅为 Host 命令分派和后台 workflow，均已纳入闭包。

## 清理前分叉

```text
Web JWT / Tauri invoke_host_command.user_id
→ Server user_id
→ Runtime
→ Orchestrator project permission

frontend api/canvas
→ 9 次再次发送 userId
→ Server handler 不读取该业务字段
→ 宽松 input envelope schema 继续接受退役身份参数
```

Canvas 的 Viewer/Editor 权限始终使用 Host 认证身份。业务参数中的 `userId` 不进入 Canvas input DTO，也不参与图、节点、workflow、媒体、生成或项目成员校验。
