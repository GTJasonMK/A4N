使用既有的 `canvas_nodes_for_projects`，通过 `std::slice::from_ref` 传入单个
项目 ID。项目图查询、空输入处理和节点查询因此只保留一套实现。

改用已有的 `config_id_in`，统一在读取时完成目标 ID 命中判断。该判断位于

`config_id_in(...).is_some()`；配置引用的读取与命中判断不再分叉为两个 helper。

行为、查询范围和错误传播不变；未新增 fallback、兼容、回退或占位逻辑。
