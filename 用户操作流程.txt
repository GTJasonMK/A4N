A4N 用户操作流程

一、账户与项目入口

登录/注册(->GitHub或Google第三方登录)
->
进入项目列表
->
选择项目入口
->
AI辅助创作->创建文本项目->进入灵感对话
自由创作->创建空白文本项目->进入项目详情或写作桌
导入项目->选择项目族/派生项目/视频画布ZIP包或旧版文本项目JSON备份->恢复项目
视频画布项目->创建自由视频项目->进入视频画布


二、文本项目主流程（AI辅助创作）

创建文本项目
->
灵感对话
->
生成首版蓝图
->
调整/优化蓝图
->
确认进入项目
->
(可选维护：世界观/角色/物体/场景/关系/事件)
->
生成/追加分部大纲
->
生成/续写章节大纲(->编辑章纲/重新生成章纲/从指定章删除后续章纲)
->
进入写作桌并选择章节
->
生成章节正文或手工写作
->
编辑并保存正文(->恢复本地草稿)(->资料检索)(->Agent正文优化)
->
(可选：生成章节结构化分析->同步角色/物体/场景等派生数据)
->
(可选：生成角色立绘/项目场景图/章节场景图/物体素材图/参考图)
->
生成结构化拍摄剧本
->
编辑场景/导演意图/镜头设计/表演节拍并保存改编
->
继续下一章

五、派生视频项目流程

派生视频项目
->

->
成片合成(->上传并插入片头/过场片段)
->
预览/下载合成成片
->
(可选：分批推送到成片后处理->同意或拒绝推送->在时间线上插入/删除/替换片段)
->
继续下一章节


六、派生漫画项目流程

派生漫画项目

->

->

->

->

->

十三、CLI / Agent 对应流程（无前端）

说明
->
CLI不复制桌面端或网页端业务逻辑
->
所有业务调用统一经过a4n-server->a4n-runtime->a4n-orchestrator
->
Agent先执行a4n --agent capabilities check确认CLI/Server合同兼容
->
再执行a4n --agent capabilities describe <command>读取参数、结果、危险等级和幂等性
->
高频账户/项目/章节/任务/工作流使用语义子命令
->
其余桌面/网页端业务能力使用a4n call <command> --args @input.json
->
长任务使用task watch或workflow watch
->
跨步骤自动化使用flow run/flow resume

本地启动
->
准备外部PostgreSQL并设置A4N_DATABASE_URL/A4N_JWT_SECRET
->
a4n local start（自动执行migration、启动Server、managed sidecar和必要且已安装的Qdrant）
->
a4n health
->
a4n --agent capabilities check
->
(人工连续操作->a4n shell)
->
(Agent操作->每次使用--agent，禁止交互)
->
a4n local stop（只停止当前CLI明确拥有的进程）

CLI公共安全规则
->
所有Agent调用使用--agent并检查JSON envelope和退出码
->
密码/OAuth code从stdin读取，Flow敏感值使用${env.NAME}
->
删除/取消/回滚/重置/移除/恢复覆盖/批量应用必须显式授权
->
Flow危险步骤同时要求spec allow_destructive=true和CLI --allow-destructive
->
下载和导出默认不覆盖旧文件，中途失败保留旧文件
->
Flow journal记录源文件SHA，源文件变化后拒绝自动resume
