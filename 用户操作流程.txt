# A4N 用户操作流程与功能说明

本文按当前桌面端/Web 前端的页面与按钮整理用户可使用的功能。按钮是否显示或可点击，取决于项目类型、当前项目阶段、账号权限、运行形态，以及是否已配置 LLM、Embedding、生图和视频服务。

## 一、推荐使用路径

### 1. 首次使用

1. 登录或注册账号。
2. 进入“设置”，配置并测试 LLM 服务；需要资料检索时配置 Embedding，需要图片或视频时再配置对应服务。
3. 返回项目列表，选择“AI 辅助创作”“自由创作”“导入分析”或“视频画布项目”。
4. 生成类任务可在进度窗口查看阶段、停止任务；后台任务也可在“设置 → 请求队列”查看。

### 2. AI 小说主流程

新建项目 → 灵感对话 → 生成并确认故事蓝图 → 维护世界观和角色档案 → 生成分部/章节大纲 → 进入写作桌生成或编辑正文 → 生成章节分析与拍摄剧本 → 生成图像，或派生漫画、视频、GALGame 项目。

### 3. 已有小说导入流程

“导入分析”或项目“导入”页 → 选择 TXT、Markdown、EPUB、DOCX → 运行项目分析 → 审核解析结果 → 接受章节 → 按需反推蓝图、分部大纲和章节大纲 → 进入写作桌继续创作。

### 4. 多媒体派生流程

文本项目准备正文和拍摄剧本 → 在项目菜单创建漫画、视频或 GALGame 派生项目 → 选择来源章节 → 运行对应流水线 → 编辑和生成素材 → 导出结果。来源文本变化后，通过“同步来源”检查并应用更新。

## 二、账户、登录与全局操作

### 登录与注册

- “登录”：输入用户名和密码进入应用。
- “注册”：填写用户名、邮箱、邀请码和密码；创建成功后自动登录。
- “使用 GitHub 或 Google 登录”：选择服务并获取授权链接，在浏览器完成授权后粘贴授权码。
- “查看授权链接”：展开完整链接，自动复制失败时可手动复制。
- “完成登录”：提交第三方授权码。
- “返回用户名登录”：退出第三方登录面板。

### 全局按钮

- “返回”：回到上一页；存在未保存正文时会先确认。
- 状态栏“内容关联/依赖状态”：查看当前项目中文本、图片、视频、漫画等内容的来源和下游关系。
- 状态栏“亮色/暗色”：切换界面主题；首次使用可跟随系统主题。
- 任务进度窗口“停止/取消”：请求停止正在运行的生成或处理任务；已经完成的阶段通常会保留。
- 模型请求“查看模型请求”：在真正提交前查看服务商、模型、提示词、参数和上下文。
- 页面异常时“重新加载”：重新载入应用；未保存内容应先自行确认或保存。

## 三、首页与项目管理

### 项目列表

- “最近项目 / 全部项目”：切换最近使用的项目族和完整项目列表。
- 项目类型筛选：“全部、文本、漫画、视频、GALGame”。
- 访问范围筛选：“全部可访问、我创建的、我协作的”。
- 项目卡片：点击进入该项目的主要入口；文本项目进入档案或写作桌，派生项目进入对应工作区。
- “设置”：进入模型、提示词、主题、队列、日志和账户配置。

### 项目邀请

- “接受邀请”：加入项目并获得邀请中指定的角色。
- “拒绝邀请”：拒绝本次项目协作邀请。
- 项目拥有者或管理员可在项目详情中撤销仍未处理的邀请。

### 新建项目

点击“新建项目”后可选择：

- “AI 辅助创作”：创建文本项目并进入灵感对话。
- “自由创作”：创建空白文本项目，可直接写作、补充设定或导入正文。
- “导入分析”：创建文本项目并进入文件导入、审核和结构反推流程。
- “视频画布项目”：创建不依赖小说来源的自由视频节点画布。

### 导入整个项目

- “导入项目”：打开项目恢复窗口。
- “选择文件”：选择项目族 ZIP、派生项目 ZIP 或视频画布 ZIP。
- “确认导入”：恢复项目数据和包内媒体；导入期间不可重复提交。

### 项目卡片和右键菜单

- “查看档案”：打开文本项目详情，查看蓝图、设定、大纲、章节和素材。
- “进入写作台/进入工作区”：直接进入文本写作桌、视频、漫画、GALGame 或画布工作区。
- “灵感对话”：继续补充创作信息或生成蓝图。
- “创建漫画项目 / 创建视频项目 / 创建 GALGame 项目”：输入派生项目标题和来源章节范围，创建独立派生项目。
- “复制为新项目”：复制当前项目为一个新的独立项目。
- “导入文本到此项目”：直接打开该文本项目的文件导入、审核和分析工具。
- “查看状态历史”：查看项目阶段的推进与回滚记录。
- “导出项目族”：文本项目导出根项目、派生项目及相关媒体的 ZIP 包。
- “导出派生项目包”：导出单个漫画、视频或 GALGame 项目包。
- 视频画布项目的导出会保存画布结构及相关媒体。
- “删除项目”：永久删除项目；该操作需要确认且不可撤销。

## 四、灵感对话与故事蓝图

### 灵感对话

- 消息输入框“发送”：提交创作想法；回车也可发送。
- AI 回复中的选项按钮：快速选择方向并继续对话。
- “查看模型请求”：查看本轮灵感对话实际发送给模型的内容。
- “创作进度”：查看标题、题材、角色、核心冲突等信息的确认情况。
- 右侧信息汇总：查看已经确认的创作信息和仍待回答的问题。
- “返回”：退出灵感页并返回项目。

### 生成蓝图

- “生成蓝图”：把当前对话整理为故事蓝图。
- 信息未完整时仍可确认“试生成草稿蓝图”，之后继续调整。
- “查看蓝图请求”：预览蓝图生成使用的模型请求。
- 生成进度窗口：查看当前阶段；可“停止生成”。

### 蓝图确认与调整

- “查看完整梗概”：查看完整故事梗概和核心设定。
- “调整蓝图”：输入希望修改的方向。
- “查看优化模型请求”：检查蓝图优化请求。
- “提交优化”：生成新的蓝图版本。
- “回到灵感对话”：继续补充信息，不确认当前蓝图。
- “确认进入项目”：保存蓝图并进入文本项目详情。

## 五、文本项目详情

### 顶部按钮与“更多项目操作”

- “返回”：回到项目列表或来源入口。
- “进入写作桌”：开始章节写作。
- “修改标题”：更新项目列表、写作桌和导出文件中显示的名称。
- “协作成员”：邀请成员、调整权限、撤销邀请、移除成员或离开项目。
- “项目阶段”：查看流程、阶段历史，按条件推进；拥有者还可预览影响后回滚。
- “灵感对话”：草稿阶段继续补充灵感和蓝图。
- “同步资料索引”：把章节、分析、大纲、蓝图、世界观和角色档案同步到 RAG 检索库；未变化内容会跳过。
- “优化蓝图”：使用 LLM 重新打磨当前蓝图并创建新版本。
- “导出小说”：导出正文或结构数据。
- “内容关联”：打开资产依赖图，查看上游来源和下游影响。

### 概览

- “推进阶段”：将项目从草稿、蓝图、大纲、写作等阶段推进到下一合法阶段；系统会检查所需蓝图或大纲是否存在。
- “项目阶段”中的回滚：先预览会受影响或删除的数据，再由拥有者确认回滚。
- “查看完整”：打开完整剧情梗概。
- “优化蓝图”：直接优化当前蓝图。
- “蓝图版本”：查看版本历史，勾选两个版本并“对比已选版本”。
- 蓝图版本菜单“恢复此版本”：用历史版本覆盖当前蓝图，但版本仓库仍保留历史。
- “协作成员”：查看当前成员数、本人角色和待处理邀请。
- 概览同时显示核心摘要、目标读者、写作风格、情感基调、章节进度和当前阶段。

### 世界观

- “查看完整设定”：打开完整世界观内容。
- “编辑世界观”：进入编辑模式。
- 编辑模式可选“结构化、JSON、纯文本”：
  - 结构化模式维护核心规则、关键地点、主要阵营等字段。
  - JSON 模式适合维护完整结构，并保留扩展字段；保存前会校验格式。
  - 纯文本模式适合自由编写设定。
- “保存世界观”：校验并保存修改。
- “退出编辑/取消”：放弃本次未保存编辑。

### 角色档案

- “档案 / 立绘”：切换文字档案和角色视觉素材。
- 点击角色卡：打开角色详情。
- 角色详情页签：
  - “弧光”：查看角色经历、变化轨迹和阶段状态。
  - “声音指纹”：查看语言习惯、表达方式和人物声音。
  - “一致性检查”：检查指定章节范围中的角色冲突。
  - “管理”：维护行为、属性、快照和删除候选。
- 一致性检查可选择起始章、结束章、当前章或全项目；“查看一致性检查请求”可先看模型输入。
- “开始检测 / 重新检查”：运行角色一致性分析。
- “刷新当前页”：重新读取当前角色数据。
- “从当前章节同步”：从同步断点开始分析章节，并写入角色事件、行为记录、删除候选、状态索引和快照。
- “查看同步请求”：在同步前检查模型请求。

角色“管理”中的功能：

- “行为记录”：按章节和数量筛选，查看角色行为证据并刷新。
- “隐性复审”：设置检查章节数与提醒阈值，生成复审建议；可查看请求、重新检查并应用建议。
- “属性事件”：筛选、新增或编辑角色属性变化事件，保存后形成可追溯记录。
- “角色快照”：按章节筛选、刷新、比较章节差异、查看状态、查看快照并回滚。
- “删除标记”：记录属性删除候选、重置标记，或确认执行属性删除。

角色“立绘”中的功能：

- “批量补缺”：为没有主立绘的角色批量生成。
- “查看批量模型请求”：检查批量生成请求。
- “生成立绘”：为单个角色生成图片。
- “上传立绘”：上传 PNG、JPEG 或 WebP。
- 角色筛选：“全部”或指定角色。
- 点击素材：查看详情和生成信息。
- “重绘立绘”：基于当前档案和参考图重新生成；可查看重绘请求。
- “设为主图”：指定后续漫画、视频等流程优先使用的立绘。
- “生成年龄变体”：生成不同年龄阶段形象。
- “查看/重新渲染提示词”：检查或重建立绘提示词。
- “生成三视图”：生成正面、侧面和背面。
- 可选择画面风格、表情变化，并上传或选择多张参考图。

### 物体档案

- “刷新”：重新读取物体档案。
- “新建档案”：填写名称、类型、重要性、出现语境、章节范围、别名、外观、材质状态、叙事用途、视觉用途、生成用途、证据和图像描述。
- 点击卡片“查看详情”：查看完整档案。
- “编辑档案”：修改字段。
- “生成素材图”：按物体档案生成项目级素材图片。
- “删除档案”：删除前会检查漫画、视频、图片等下游依赖；存在依赖时需先选择处理方式。

### 场景档案

- “刷新”：重新读取场景档案。
- “从章节同步”：根据章节分析补充或更新场景。
- “新建场景”：填写名称、类型、重要性、上级场景、章节范围、别名、基础定义、视觉特征、空间布局、氛围、证据和图像描述。
- 点击卡片“查看详情”：查看出场次数、出入口、规则和当前状态。
- “编辑场景”：修改场景资料。
- “生成场景素材图”：为后续漫画和视频生成可复用场景图。
- “删除场景”：有下游素材时先处理依赖冲突。

### 角色关系

- “关系图 / 角色列表”：切换图形关系网和按角色汇总的列表。
- “缩小 / 放大 / 还原视图”：调整关系图画布。
- 拖动角色节点：固定自定义位置；拖动画布可平移。
- “恢复自动布局”：重新计算节点位置。
- 点击角色：查看该角色的关系列表。
- 点击关系线或“查看关系详情”：查看双方关系描述、同步章节和详情。

### 事件脉络

- “刷新事件脉络”：重新读取章节分析中的事件和伏笔。
- 搜索框：按事件、章节、地点或角色搜索。
- 筛选项：按角色、事件类型和重要性筛选。
- 点击章节：跳转写作桌的对应章节。
- 每章可查看摘要、人物、关键词、关键事件、伏笔埋设、伏笔回收和悬念状态。

### 大纲

分部大纲：

- 设置“生成部数”和“每部章节数”。
- “生成分部 / 追加分部”：生成首批或在现有分部后追加。
- “查看生成请求 / 查看追加请求”：预览模型调用。
- 点击分部卡片：查看分部目标、剧情和章节范围。

章节大纲：

- 设置要追加的章数。
- “生成章纲 / 追加章纲”：生成章节级标题与摘要。
- “查看生成请求 / 查看追加请求”：预览模型调用。
- 点击章纲：查看详情。
- 编辑状态下可修改标题和摘要，并“保存”或“取消”。

单章“更多章纲操作”：

- “编辑章纲”。
- “预览重生成提示词”。
- “重新生成本章纲”。
- “从本章删除到结尾”：删除当前章及之后的章纲，需要确认。

“大纲高级工具”：

- 查看生成进度，开启/关闭自动刷新，或手动刷新。
- “分析章纲节奏 / 重新分析”：检查章节节奏分布。
- 选择分部后“生成本部章纲”。
- “批量生成各部章纲”。
- “续作下一部”。
- “重写选中分部”。
- “重新生成所有分部”。
- 编辑节拍映射 JSON，并“应用节拍”。
- “重写最后一部”。
- 删除最近分部或最近章纲；删除前会确认影响范围。

### 图像

- “本章图像 / 项目图库”：切换当前章节图片和全项目素材。
- “仅看收藏”：只显示已收藏图片。
- “刷新图库”：重新加载素材和生成状态。
- “导入图片”：上传 PNG、JPEG 或 WebP，并填写用途和描述。
- “生成图片”：输入场景提示词；可“查看模型请求”后开始生成。
- 章节图片会绑定章节，并记录生成时的正文指纹；正文变化后可能显示“需更新”。
- “从物体档案生成素材”：选择物体档案和风格，复制提示词、查看模型请求或直接生成。
- 可按素材类型、页码和分镜分组查看。
- 星标按钮“收藏/取消收藏”。
- 点击图片打开详情：
  - “概览”：查看缩略图、用途、质量等信息。
  - “来源”：查看提示词、关联章节、生成来源和原始数据。
  - “管理”：修改提示词、素材分类、关联分镜并保存。
  - “复制原始 JSON”。
  - 设置质量评分，范围为 0–1。
  - “删除图片”：会解除漫画或视频中的相关绑定，需要确认。

### 导入与分析

文件导入：

- “选择文件”：支持 TXT、Markdown、EPUB、DOCX，单文件最大 100 MB。
- 文件类型下拉框：指定或确认导入类型。
- “开始导入”：解析文件并生成审核项。

审核队列：

- 查看文件名、解析章节、编码和去重率。
- 复选框：选择一个或多个审核项。
- “接受审核”：把审核结果写入项目章节。
- “批量接受所选”：一次接受多个审核项。
- “拒绝审核”：保留记录但拒绝写入。
- “删除审核记录”：永久移除该审核项。
- 点击审核项查看详情。
- “高级编辑”：编辑解析/分析 JSON。
- “更新审核状态”和“保存修改”。

导入项目分析：

- “分析项目 / 继续分析”：分析导入内容并提取结构信息。
- “查看分析模型请求”：检查分析请求。
- 查看阶段进度和已完成内容。
- “停止分析”：停止后已完成部分仍保留。

辅助工具：

- “段落去重”：粘贴段落并检查重复，查看去重结果。
- “结构反推”：可选蓝图、章节大纲或分部大纲。
- “使用项目上下文”：决定反推时是否参考现有项目资料。
- “仅预览”：只生成结果，不写入项目。
- “查看模型请求”。
- “反推并应用”：生成结果并写入项目；会改变现有结构数据。
- “查看反推结果”。

### 章节列表

- 显示章节数、总字数、章节状态和单章字数。
- 点击章节：打开写作桌并定位到该章。
- “导入章节”：输入章节序号、可选标题和正文，确认后直接写入项目。
- 没有章节时“进入写作桌生成第一章”。

### 导出小说

- 导出格式：“TXT 纯文本、Markdown、EPUB、PDF、TXT + Markdown”。
- Markdown、EPUB 和批量导出需要填写书名和作者。
- “下载”：生成并下载文件；导出进度中可停止。
- “结构数据”可展开下载“大纲 JSON”和“角色 JSON”。
- 漫画图片、视频成片和 WebGAL 工程需在对应派生工作区导出。

## 六、写作桌

### 导航和章节选择

- “返回”：离开写作桌；有未保存正文时先确认。
- “项目详情”：返回文本项目档案。
- “隐藏左侧栏 / 显示左侧栏”：调整编辑空间。
- “上一章 / 下一章”：切换相邻章节。
- “资料检索 / 写作助手”：显示或再次点击关闭右侧面板。
- 移动端“更多”中可打开“项目详情”和“角色档案”。
- 左侧“刷新章节”：重新载入章节和章纲。
- 搜索框：按章节号、标题和章纲搜索；“清空搜索”恢复全部。
- 点击章节卡片：切换当前章；本地草稿会标记提示。
- “本章章纲”：打开当前章节的标题和摘要。

### 正文编辑与保存

- “正文”页签：手工编辑章节正文。
- 字数和章节状态会实时显示。
- “保存修改”：把正文写入项目；支持 Ctrl+S 或 Cmd+S。
- 切章或离开时如有未保存修改，会提示保存、放弃或取消离开。
- 浏览器/桌面本地草稿可用于异常退出后的恢复；正式内容仍应点击保存。

### 写作助手：生成

- “生成 / 优化”：切换正文生成和正文优化模式。
- “写作备注 / 重试要求”：补充本章风格、剧情和重试要求。
- “正文长度”：设置最少和最多字数；区间无效时会阻止生成。
- “查看模型请求”：预览本章生成提示词和上下文。
- 主按钮“开始生成 / 重新生成”：流式生成章节正文。
- “取消生成”：停止当前生成。
- 生成过程中可查看任务状态、消息和诊断任务编号。
- “场景管理”：打开本章场景列表。
- “重置生成数据”：删除生成数据并重置章节生成状态；不可恢复，但蓝图版本历史会保留。

### 正文优化

- 在写作助手切换到“优化”，输入优化目标并生成修改提案。
- 修改预览会在正文中显示原文和新文。
- 每条修改可选择“接受”或“拒绝”。
- “接受全部”“同步已接受的修改”或“完成审阅”把结果写回编辑区。
- “批量处理”可接受全部或放弃全部。
- 正文已经变化、补丁无法唯一定位或补丁重叠时，系统会显式阻止写回。

### 章节分析

- “分析”页签：查看摘要、关键词、角色、地点、物品、标签、基调、时间、关键事件、角色状态、伏笔和识别物体。
- “预览模型请求”：查看章节分析请求。
- “生成分析 / 重新分析”：分析当前正文。
- “继续同步”：分析已完成但派生档案同步未完成时，从断点继续。
- “预览同步请求”：查看继续同步会使用的请求。
- 前序章节分析未完成或当前正文为空时，会显示阻止原因，不会静默跳过。

### 资料检索

- 在“资料检索”面板输入人物、事件、设定或其他关键词。
- “检索”：从已同步的章节、大纲、蓝图、世界观和角色档案中寻找相关资料。
- “清除结果”：清空本次检索。
- 结果显示相关度、资料范围和候选内容。
- 检索结果不完整时，先在项目详情点击“同步资料索引”。

### 本章图像

- “图像”页签固定到当前章节，支持导入、生成、收藏、编辑元数据和删除。
- 图片会记录当前正文指纹；正文改变后可据此判断素材是否过期。

### 剧本改编

- “剧本改编”页签把章节正文转换为结构化拍摄剧本。
- “生成拍摄剧本”：首次生成完整结构。
- “生成下一个场景”：在已有内容后继续生成一个场景。
- “生成全部剩余场景”：补齐本章后续场景。
- “重新生成拍摄剧本”：重建本章剧本。
- “查看模型请求”：检查生成请求。
- “编辑”：进入结构化编辑器。
- “保存改编”：保存修改。

可编辑内容包括：

- 导演声明、核心戏剧问题、主角行动、观众体验、视觉/视点/空间/声音/节奏策略。
- 场景标题、场景标头、目标、阻碍、地点、时间、参与人物、焦点人物和场景转场。
- 剪辑、视点、信息控制、空间连续性、轴线和运动方向。
- 镜头标题、叙事目的、主体、构图、景别、角度、机位高度、运动、覆盖和时长。
- 人物调度、对白、环境声、音效、音乐、静默设计和表演节拍。

### 场景管理和角色档案工作台

场景管理：

- 查看、添加、编辑和删除本章场景。
- 生成场景相关数据，并为后续剧本、漫画和视频提供结构依据。

角色档案工作台：

- “刷新”：重新载入角色档案。
- “新建角色”：填写姓名、性别、年龄、性格、背景和外观。
- “发现角色”：从正文中识别新角色。
- “查看角色发现请求”：预览识别请求。
- “同步全部角色”：从章节批量更新角色档案。
- “预览同步请求”。
- 选择角色后查看深度详情和属性历史。
- “删除档案”：删除角色档案前会确认影响。

## 七、派生项目共通操作

### 创建前提

- 漫画、视频和 GALGame 项目以文本项目及来源快照为基础。
- 建议先完成来源章节正文，并生成与当前正文匹配的拍摄剧本。
- 创建时填写派生项目标题和章节范围。

### 来源同步

派生项目顶部“同步来源/同步源文本”：

- “检查更新”：只比较来源与当前派生项目，不修改内容。
- 查看源文本变化、当前项目变化、冲突范围和严重级别。
- “应用安全更新”：应用没有冲突的来源变化。
- 冲突项“保留当前”：忽略该项来源变化，保留派生项目本地内容。
- GALGame 冲突可选择按最新来源“重新生成场”。
- “重新检查”：重新生成同步计划。
- “分离来源项目”：停止跟随原项目，保留当前来源为固定版本；分离后不能继续自动同步。

## 八、视频项目

### 项目入口

- “返回项目列表”。
- “同步源文本”：打开来源同步。
- “画布模式”：进入节点式视频画布。
- 来源章节列表：选择要制作的视频章节。
- 工作区依次分为“素材生成、片段规划、片段生成、成片合成、成片后处理”。

### 素材生成

- 搜索框：搜索场景或物品。
- “类型、状态、排序”：筛选角色、场景、物体及素材状态。
- “刷新素材管理数据”。
- “风格模板”：选择预设画风；也可填写自定义风格要求。
- “批量生成缺失素材”：为当前筛选中缺少素材的档案批量生成。
- “批量更新过期素材”：重生成正文或档案变化后过期的素材。
- 点击素材图：打开大图或详情。
- “复制素材提示词”。
- “上传素材图”：上传自有素材，并可勾选“上传后设为主素材”。
- “设为主素材”：让后续视频优先使用该图。
- “收藏/取消收藏”。
- “重新生成素材图”。
- “删除素材图”：会同步解除相关视频参考图绑定。

### 片段规划

- “选择要规划的拍摄场景”：按拍摄剧本场景制作片段规划。
- “规划此场景”：首次生成片段列表。
- “重新规划此场景”：重建当前场景规划。
- “继续生成”：从未完成的规划断点继续。
- “重试加载”：重新读取失败的保存结果。
- “删除片段规划”：删除规划和受影响的下游提示词/视频，需要确认。
- “规划配置”：编辑共享风格、氛围和细节要求。

### 片段生成

- 选择片段卡片进入配置。
- 按片段选择可用执行方案，例如独立首尾帧、首帧续接、分镜板、参考图片/媒体或 Chat 外部生成。
- 首帧、尾帧、续接首帧和分镜板槽位可生成、导入、选择或删除图片。
- “续接首帧”：选择更早片段已经采用的视频，并使用其尾帧作为当前首帧。
- 管理生成参考图和参考媒体；保存参考媒体草稿。
- “生成最终提示词”：在必需素材齐全后生成视频提示词。
- “查看模型请求”：检查图片或视频模型请求。
- “保存更改”：保存编辑后的最终提示词。
- “复制提示词”：复制到剪贴板，可用于外部生成服务。
- “优化提示词”：让 LLM 优化当前提示词。
- “生成视频”：调用已配置的视频服务。
- “导入已有视频”：导入外部生成结果。
- “刷新记录”：更新候选视频状态。
- “查看完整视频提示词”。
- “采用”：把候选视频设为当前片段参与合成的结果。
- “收藏/取消收藏”。
- “刷新生成状态”。
- 输入起止秒数并“裁剪选中视频”。
- “删除视频”：删除候选记录和媒体，需要确认。
- 修改片段执行方案时，系统会提示当前提示词、候选视频和采用状态可能失效。

### 成片合成

- 片段列表显示当前顺序、时长、状态和是否已推送。
- “插入片头素材”：在没有片段或片头位置导入额外视频。
- “在此后插入衔接片段”：在两个片段之间导入过场。
- “删除衔接片段”。
- 可配置片段候选时长并调整参与合成的片段。
- “生成预览 / 更新预览”：合成当前顺序并生成可播放预览。
- 菜单“下载成片预览”。
- 设置“推送段数”后点击“推送后处理”，分批把成片送入后处理。
- 最新推送未同意或拒绝前，不能继续推送下一批。

### 成片后处理

- 选择推送批次，查看状态和后处理预览。
- “同意推送”：接受当前批次并允许后续批次继续。
- 更多状态操作可拒绝或更新当前推送状态。
- 在时间线上设置一根标记后“上传并插入”。
- 设置两根标记形成区间后“上传并替换”。
- 菜单“删除选中区间”。
- 拖动时间线和标记可精确定位剪辑点。
- 每次编辑生成新版本，可在批次和版本之间切换查看。

## 九、自由视频画布

### 节点库

节点按类别提供：

- 输入：文本、图片、视频、音频。
- 操作：文本模板、LLM 文本处理、图片生成、视频生成、抽取帧、裁剪视频、组装视频。
- 探针：文本、图片、视频、音频内容查看。
- 输出：文本、图片、视频、音频输出。

桌面端把节点拖入画布；移动端点击节点，将其添加到当前画布视图中心。

### 画布操作

- 拖动节点调整位置。
- 从端口拖线建立上下游连接；选中连线可查看属性或删除。
- 选中节点后在属性面板编辑输入、参数、模型配置和输出。
- 导入本地图片、视频；自由画布还可导入音频。
- “保存画布”：保存节点、连线、参数和画布位置。
- “运行完整画布”：按依赖顺序运行全部可执行节点。
- 节点菜单：
  - “查看内容”：查看当前节点输入或输出。
  - “查看模型请求”：预览模型节点请求。
  - “运行节点”：只运行当前节点。
  - “运行到该节点”：运行当前节点所需的全部上游。
  - “删除节点”。
- 移动端“打开节点库”和“打开属性面板”。

### 运行记录

- 查看工作流状态、完成比例、阶段消息、进度事件和诊断信息。
- “刷新运行记录”。
- “停止运行”：取消当前工作流。
- “继续运行”：从未完成节点恢复。
- 节点状态包括就绪、运行、完成、失败和缺失；本地媒体丢失时会明确提示重新导入。

## 十、漫画项目

### 漫画流水线

- “返回项目列表”。
- “同步来源”。
- 选择来源章节；正文为空或正在生成时会阻止漫画操作。
- “生成本章漫画”：启动漫画 8 步流水线。
- “继续生成”：从可用断点继续，复用已完成阶段。
- “更新本章漫画 / 重新生成本章漫画”：正文或来源变化后重建。
- “开始阶段”：选择从哪一步开始重跑。
- “查看生成请求 / 查看继续生成请求 / 查看重新生成请求”。
- “停止生成”。
- 查看流水线阶段、进度和错误。
- “从所选阶段重新生成”。
- “补齐缺失立绘”：为没有主立绘的角色生成素材。
- “删除本章漫画”：删除本章提示词和相关产物，不可撤销。

流水线会完成角色绑定、关键对白/想法/旁白提取、场景与视觉锚点、关键物品、章节节奏、分页规划和整页提示词等处理。

### 整页漫画

- 左侧选择漫画页。
- “提示词与参考图 / 成图”：切换工作视图。
- 查看整页提示词、构图信息、角色、文字、来源状态和参考图。
- “编辑提示词”并保存。
- “优化提示词”：输入优化方向并调用 LLM。
- “删除当前页提示词”。
- “参考图绑定”：绑定角色主立绘、项目图片或其他素材；已有成图时修改绑定会先处理下游冲突。
- “查看生成图片请求”。
- “生成图片 / 更新图片 / 重新生成图片”。
- 点击成图“查看大图”。
- 正文变化导致提示词过期时，会提示从受影响阶段重新生成。

## 十一、GALGame 项目

### 剧本生成

- “返回项目列表”。
- “同步来源”。
- “刷新 Galgame 剧本”。
- “生成剧本”：运行 GALGame 多阶段管线。
- “继续生成”：从未完成阶段继续。
- “生成选项”：选择从头开始，或从拍摄剧本投影、剧本改编、角色演出、视觉规划、分支设计、写入剧本、资产意图等阶段开始。
- “查看模型请求”。
- “重新生成剧本”。
- “停止生成”。
- 管线状态面板显示阶段、进度和错误。
- “导出 WebGAL 工程”：下载可运行的 WebGAL 项目包。

### 场次编辑

- 移动端“场次 / 编辑”切换。
- 点击场次进入编辑。
- 可修改标题、地点、时间、背景需求、场次类型和下一场。
- “绑定背景素材 / 取消绑定背景”。
- “添加行”：在场尾新增剧本行。

### 剧本行编辑

- 行类型：“旁白、对白、独白、演出、选择”。
- 对白和独白可绑定说话角色。
- 设置站位、表情和姿势。
- 编辑文本后保存。
- “上移 / 下移”：调整行顺序。
- “在下方插入”：插入新行。
- “删除行”。
- 设置事件 CG 开关、CG 画面描述和优先级。
- 设置转场：无转场、直接切换、淡入淡出或叠化。
- 选择行可编辑 2–3 个选项和目标场：
  - “添加”增加选项，最多 3 个。
  - 删除选项，最少保留 2 个。
  - “保存选择支”。
  - 缺失目标或支线未回收敛时会阻止验收和导出。

### 视觉和音频资产

- “规划视觉资产 / 重新规划”：生成背景、角色差分和事件 CG 需求。
- “生成资产”：批量生成规划中的视觉素材。
- 可对单个背景、角色差分或事件 CG 单独生成。
- 角色差分面板可检查不同表情和姿势的生成状态。
- 场次可绑定背景，行可绑定或解绑 CG。
- “导入 BGM / 导入 SFX”：上传音频并自动记录媒体信息。
- 也可通过素材编号绑定已有 BGM、SFX 或 CG。
- 绑定后可播放音频、查看图片并取消绑定。

## 十二、设置与系统维护

设置分类包括：LLM 服务、嵌入模型、生图模型、视频生成、提示词管理、主题配置、高级配置、管理员、请求队列、日志、账户与应用。

### 通用模型配置按钮

LLM、Embedding、图片和视频配置大体使用相似操作；具体按钮以当前配置页为准：

- “新建配置”：创建服务配置。
- “刷新”：重新读取配置列表。
- 选择配置：查看和编辑当前配置。
- “保存 / 创建”：保存表单。
- “取消新建”：放弃新配置。
- “设为默认/启用”：设为当前默认配置。
- “检测模型列表”：向服务商探测可用模型并回填模型选择项；探测失败会保留明确错误。
- “测试连接”：LLM、Embedding 和图片配置可使用已保存配置验证服务。
- “查看模型请求”：在提供测试入口的配置页预览连接测试请求。
- “保存时清除密钥”：开启后保存配置时移除已保存的 API Key；关闭时保留原密钥。
- “删除配置”：删除非只读、非受保护配置。
- 切换配置、刷新或离开时，如存在未保存修改会先确认。

### LLM 服务

可配置：

- 服务商、模型、接口地址和访问密钥。
- 并发数、超时、上下文窗口、最大输出。
- 高级 JSON 请求参数。
- 按生成场景设置输出预算，并刷新或保存预算。

### 嵌入模型

可配置：

- API 或本地后端、模型、接口地址、访问密钥。
- 向量维度和批量大小。
- FastEmbed 本地模型可下载、查看状态和删除。
- RAG 检索需要可用的 Embedding 配置和资料索引。

### 生图模型

可配置服务商、模型、接口、访问密钥、默认宽高和并发数；用于角色立绘、场景图、物体图、章节图和漫画图片。

### 视频生成

可配置服务商、模型、接口、访问密钥、宽高、FPS、并发，以及固定或范围时长模式、默认/最小/最大时长和可用固定档位。当前没有独立的视频配置测试命令，通过“检测模型列表”和目标视频请求的只读预览确认配置。

### 提示词管理

- 分类标签：按功能域筛选提示词。
- 搜索框：按名称或内容搜索。
- “刷新”：重新读取提示词。
- “载入默认提示词”：补充或恢复系统默认集合。
- 选择提示词后编辑并“保存”。
- “恢复默认”：恢复当前提示词的默认内容。
- “版本历史”：查看保存记录，选择两个版本并对比。
- 项目独立覆盖：选择项目，为该项目保存专用提示词版本；可移除覆盖恢复全局版本。
- 存在未保存草稿时，切换或刷新会先确认。

### 主题配置

- 切换“用户主题 / 系统主题”范围。
- “刷新主题”。
- “激活”：立即应用主题。
- “重命名主题”。
- “导出主题”。
- “查看 CSS”：查看主题变量。
- “删除主题”。
- “创建新主题”：输入名称，从亮色或暗色模板开始。
- “导入主题”：粘贴导出的 JSON 配置并导入。

### 高级配置

- “导出配置文件”：备份模型、提示词、主题和系统配置。
- “导入配置文件”：从 JSON 恢复。
- “覆盖同名项”：
  - 开启时替换已有同名配置。
  - 关闭时保留已有项，只补充新项。

### 账户与应用

- 修改邮箱和头像地址并保存。
- 修改密码：输入当前密码和新密码。
- 查看登录会话：查看其他活动会话、会话编号、设备信息、状态和时间。
- “重新获取凭证”：登录状态异常时，用本机保存的凭证重新建立当前会话。
- 登出当前账号。
- 查看应用名称、版本、运行形态和技术信息。
- “刷新路径”：读取数据、媒体、日志等存储位置。
- “复制路径”：复制指定本地目录。
- 管理员可“扫描”孤儿项目目录，并在确认后“清理孤儿项目目录”。

### 请求队列

- 每 5 秒自动刷新，或点击“立即刷新”。
- 查看 LLM、图片、视频、向量和后台任务的等待/执行数量。
- 查看高、中、低优先级任务。
- 查看活跃工作流、任务历史和持久化运行记录。
- “取消任务 / 取消工作流”。
- 展开运行详情查看进度事件和诊断信息。
- “继续运行”：恢复允许续传的持久化工作流。

### 日志与生成调用分析

- “生成调用分析 / 运行日志”：切换统计和原始日志。
- 选择统计范围、日志行数和日期。
- “刷新”。
- 设置日志过滤级别，并“应用级别”。
- 查看 LLM、图片、视频调用量、令牌命中、工作流和最近调用。
- “复制路径”：复制日志目录。

### 管理员

仅管理员可见：

- “概览”：查看服务状态、版本和后台概况，并刷新。
- “用户”：查看用户，创建新用户，查看令牌摘要和最近用量。
- 用户菜单“调整角色”：修改用户角色。
- 用户菜单“禁用用户”：禁止该账户继续登录，但保留已有数据。
- “新增邀请码”：生成供注册使用的邀请码。
- “项目”：查看系统项目并刷新。
- “任务”：查看后台任务，刷新并取消任务。
- “配置”：维护服务器共享的 LLM、图片、视频和 Embedding 默认配置。
- “趋势”：选择统计范围并刷新用量趋势。

## 十三、协作、权限和安全提示

### 项目角色

- “拥有者”：完整管理项目，可推进和回滚阶段、管理成员、删除项目。
- “管理员”：可编辑项目并管理协作者，但不能代替拥有者执行所有权操作。
- “编辑者”：可编辑正文、设定、素材和派生内容。
- “只读成员”：主要查看项目；编辑按钮和部分维护页签会隐藏或禁用。

### 协作按钮

- 输入用户名或邮箱，选择“管理员、编辑者、只读成员”，点击“邀请”。
- 成员角色下拉框：调整非拥有者角色。
- 成员菜单“移除成员”。
- 邀请菜单“撤销邀请”。
- 非拥有者菜单“离开项目”；离开后需重新受邀才能访问。

### 依赖和过期提示

- 修改或删除已有下游产物的角色、物体、场景、图片、漫画提示词或视频规划时，系统会先显示依赖冲突处理。
- 正文、拍摄剧本、来源快照或提示词变化后，相关图片、漫画页或视频可能标记为“过期/需更新”。
- 不要通过保留下游旧数据来掩盖来源变化；只有确认旧产物仍有效时才选择保留。

### 危险操作

以下操作通常不可撤销，必须仔细阅读确认窗口：

- 删除项目、章节后续大纲、漫画产物、图片或视频。
- 重置章节生成数据。
- 回滚项目阶段或角色快照。
- 删除角色属性、物体档案、场景档案。
- 应用结构反推覆盖、来源同步冲突决策。
- 分离派生项目来源。
- 清理孤儿项目目录。

### 模型和数据注意事项

- 不同 AI 功能需要对应配置：文本使用 LLM，RAG 使用 Embedding，图片使用生图服务，视频使用视频服务。
- 使用系统默认服务时，仍可能需要在个人配置中保存自己的 API Key。
- 生成、导入、导出和同步任务失败时，应查看明确错误和任务进度，不要把“已提交”当作“已完成”。
- 不要在项目或配置中保存真实密钥的明文导出文件；配置备份应按敏感文件保管。

## 十四、CLI / Agent 用户入口（可选）

CLI 与桌面/Web 共用后端业务能力，适合自动化、批处理和 Agent 调用。

- 本地服务：a4n local start、a4n health、a4n local stop。
- Agent 开始前：a4n --agent capabilities check。
- 查看命令合同：a4n --agent capabilities describe <command>。
- 高频语义命令覆盖 auth、project、chapter、task、workflow 等功能。
- 其他功能使用 a4n call <command> --args @input.json。
- 长任务使用 task watch 或 workflow watch 等待终态。
- 当前 CLI 没有 flow 子命令；多步骤流程使用普通脚本组合 call、task、workflow 和 media 命令，并持久化返回的 ID。
- 密码、OAuth code 和密钥应从标准输入或环境变量读取，不写入命令历史、脚本或参数文件。
- 删除、回滚、取消、覆盖、批量应用等危险操作需要显式授权参数。
- 下载和导出默认不覆盖已有文件，确认后再使用强制覆盖。
- CLI 不包含浏览器本地草稿、拖拽画布和可视化时间线等纯界面交互，但业务结果与前端使用同一后端合同。
