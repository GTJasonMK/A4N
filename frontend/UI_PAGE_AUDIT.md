# 逐页面 UI / UX 审查台账

继续自第一轮公共层优化。**第一轮的 132 张截图不代表全部页面完成**；本轮按可达工作面逐项审查，并保留原暖书房默认配色、iOS 风格、所有功能与可访问性、Lucide 和原始样式预算。

创作者的任务顺序是“定位作品或资料 → 阅读/编辑 → 确认状态 → 继续创作或交付”。主操作和高频输入优先；版本、参数、诊断按需要展开。频率是基于工作流的推定，不冒充遥测数据。

每项必须留下：入口/源码、任务与频率、注意力顺序、有内容样本、实际缺陷、改动和交互复核。未渲染的项目明确标记为待实屏；无缺陷的页面记录具体通过依据，不做无理由的装饰改动。

## 已登记问题

### X01 / X02：视频画布的节点库与属性

- 任务/频率：高；添加节点 → 连接 → 选节点 → 修改属性 → 执行 → 查看输出。
- 样本：有文本输入与图片生成节点的真实生产页面，1440px 和 1024px。
- 代码证据：`VideoStudioCanvas.tsx` 桌面节点按钮只有 drag，没有 click；属性栏在 1100px 以下隐藏，按钮和弹窗却仅在 768px 以下出现。
- 缺点：桌面键盘不能添加节点；平板宽度无法打开节点和连线属性，也找不到属性栏中的运行信息。
- 修复：抽屉按现有侧栏是否可见决定入口；节点库保留拖动并支持点击/键盘添加。
- 证据：`ui-page-audit/ui-pages.e2e.mjs` 两项优化前失败、优化后通过；`canvas-before.log` / `canvas-after.log`。完整有内容画布的各类属性仍单独验收。

### S02：图片配置尺寸输入

- 任务/频率：偶发配置，但需要连续键盘录入；尺寸名称 → 宽/高 → 更多尺寸 → 保存。
- 代码证据：`ImageConfigEditor.tsx` 把正在编辑的宽/高拼入 React key。
- 缺点：每输入一个字符都可能重新挂载该输入框并丢失焦点。
- 修复：行身份不再包含正在输入的值；尺寸独占整行，宽高各有可见标签。编辑区根据实际容器宽度排列字段。
- 证据：优化前输入 `1536` 只得到 `1`；优化后完整数字与焦点都保留。900px 截图中宽高完整可读。已有、新建、只读、保存及模型探测继续分别覆盖。

### S06：Agent 技能配置

- 任务/频率：按需配置；类别 → 技能用途和开关 → 待保存 → 保存反馈。
- 代码证据：`AgentTab.tsx` dirty 只设 true，改回原值仍锁类别；保存时允许继续编辑，但回包会覆盖后续草稿。
- 修复：dirty 从保存值与当前勾选导出；保存响应只重置未被继续编辑的草稿。类别在手机改为选择器，技能名称先于内部标识，列表按内容收缩。
- 证据：重复勾选恢复干净状态；延迟保存期间的第二次编辑保留。三个优化前失败序列均有优化后通过结果，见 `settings-interaction-before.log` / `settings-interaction-after.log`。

### 共享修复不等于跳过逐页验收

- 配置字段容器使用 `page-layout.css` 的现有命名空间；未改暖书房色值。当前CSS源为4,582行/130,513字节，仍低于原始4,698行/137,890字节；最终以完成后的预算脚本结果为准。
- 管理数据加载失败由现有 `useAdminSectionLoader` 统一返回带作用域的错误；趋势停止把失败当作永久加载，用户/项目/任务/概览分别保留可见错误与原刷新入口。失败 → 重试动作尚在验证，不提前记通过。
- 图片卡片原来在按钮内嵌入交互图片，放大阻断父按钮；现在主操作使用普通图片，独立兄弟放大按钮共用原灯箱。已逐个追踪通用图库、立绘、立绘参考、写作资料卡、视频首尾帧/连续性/参考媒体/插入参考图。各入口分别留下主点击与放大动作证据后才闭环。
